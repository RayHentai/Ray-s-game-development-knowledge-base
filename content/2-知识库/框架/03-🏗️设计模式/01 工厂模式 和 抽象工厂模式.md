## 核心理解


**简单工厂模式：** 定义了一个创建对象的类，由这个类来封装实例化对象的行为。

**工厂方法模式：** 定义了一个创建对象的抽象方法，由子类决定要实例化的类。工厂方法模式将对象的实例化推迟到子类。

 **抽象工厂模式：** 定义了一个接口用于创建相关或有依赖关系的对象族，而无需明确指定具体类。

### 简单工厂模式

以工厂生产产品A、B、C为例

```csharp
interface IProduct {  }
//产品A、B、C
class ProductA : IProduct {  }
class ProductB : IProduct {  }
class ProductC : IProduct {  }

//生产产品的工厂（有一个实例化对象的方法）
class Factory
{
    public static IProduct CreateProduct(string product)
    {
	    private IProduct result;
        switch (product)
	    {
		    case "productA":
			    result = new ProductA();
			    break;
		    case "productB":
			    result = new ProductB();
			    break;
			case "productC":
			    result = new ProductC();
			    break;
			default: 
				result = null; 
				break;
	    }
	    return result;
    }
}
//工厂生产产品（实例化对象）
Factory.CreateProduct("productA");
Factory.CreateProduct("productB");
Factory.CreateProduct("productC");
```

**潜在问题：** 类的创建依赖工厂类，如果想要拓展程序，必须对工厂类进行修改，这违背了开闭原则——已有的代码不改，新功能通过新增代码来实现

**解决方式：** 可以定义一个创建对象的抽象方法，并创建多个不同的工厂类实现该抽象方法，一旦需要增加新的功能，直接增加新的工厂类就可以了，不需要修改之前的代码。这种模式即工厂方法模式

### 工厂方法模式

以A工厂生产A产品，B工厂生产B产品为例

```csharp
// 产品接口
//1 确定一个产品接口Product
interface IProduct 
{
	//包含一个doSomething()方法，用于执行产品的操作
    void DoSomething();
}

//2 发现了两个具体产品类型ConcreteProductA 和 ConcreteProductB
//分别发现了产品接口中的方法
// 具体产品类A
class ConcreteProductA : IProduct
{
    public void DoSomething()
    {
        Console.WriteLine("ConcreteProductA do something");
    }
}

// 具体产品类B
class ConcreteProductB : IProduct
{
    public void DoSomething()
    {
        Console.WriteLine("ConcreteProductB do something");
    }
}


// 工厂接口
//3 确定了工厂接口Factory
interface IFactory
{
	// 包含一个createProduct()方法，用于创建产品对象
    IProduct CreateProduct();
}

//4 发现了两个实体工厂类 ConcreteFactoryA 和 ConcreteFactoryB
// 分别发现了工厂接口中的方法，根据需要创建不同的产品对比
// 具体工厂类A
class ConcreteFactoryA : IFactory
{
    public IProduct CreateProduct()
    {
        return new ConcreteProductA();
    }
}

// 具体工厂类B
class ConcreteFactoryB : IFactory
{
    public IProduct CreateProduct()
    {
        return new ConcreteProductB();
    }
}

//5 在客户端中 创建了工厂对象 并使用工厂对象分别创建了实体的产品对象
//通过工厂的创建方法 可以轻松地获取产品对像 并调整使用其他方法进行操作
// 客户端代码
class FactoryPatternExample
{
    static void Main(string[] args)
    {
        // 创建工厂对象
        IFactory factoryA = new ConcreteFactoryA();
        IFactory factoryB = new ConcreteFactoryB();

        // 使用工厂对象创建产品对象
        IProduct productA = factoryA.CreateProduct();
        IProduct productB = factoryB.CreateProduct();

        // 调用产品对象的方法
        productA.DoSomething();
        productB.DoSomething();
    }
}
```

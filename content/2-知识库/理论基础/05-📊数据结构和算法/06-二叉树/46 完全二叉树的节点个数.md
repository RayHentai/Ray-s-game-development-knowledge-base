## 题目描述

给你一棵 **完全二叉树** 的根节点 `root` ，求出该树的节点个数。

完全二叉树的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 `h` 层（从第 0 层开始），则该层包含 `1~ 2h` 个节点。

## 解法一：递归（最优）

完全二叉树有一个特性：如果一棵子树的最左侧深度等于最右侧深度，那它一定是满二叉树，节点数是 `2^深度 - 1`，可以直接用公式计算，不需要遍历。

用这个思路写终止条件可以降低时间复杂度和空间复杂度

**思路：**

**时间复杂度：** O(log²n)
**空间复杂度：** O(log n)

```csharp
public class Solution {
    public int CountNodes(TreeNode root) {
        return traversal(root);
        int traversal(TreeNode root){
            if (root == null)
                return 0;
            int depth = LeftMaxDepth(root);
            if (depth == RightMaxDepth(root))
                return (1 << depth) - 1;
            else
                return traversal(root.left) + traversal(root.right) + 1;
        }
        int LeftMaxDepth(TreeNode root) {
            if (root == null)
                return 0;
            return LeftMaxDepth(root.left) + 1;
        }
        int RightMaxDepth(TreeNode root) {
            if (root == null)
                return 0;
            return RightMaxDepth(root.right) + 1;
        }
    }
}
```

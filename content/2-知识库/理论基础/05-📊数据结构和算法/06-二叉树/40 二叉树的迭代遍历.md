## 前序遍历

**思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<int> PreorderTraversal(TreeNode root) {
        Stack<TreeNode> stack = new();
        List<int> result = new();
        if (root == null)
            return result;
        stack.Push(root);
        while (stack.Count > 0){
            TreeNode temp = stack.Peek();
            result.Add(stack.Pop().val);
            if (temp.right != null)
                stack.Push(temp.right);
            if (temp.left != null)
                stack.Push(temp.left);
        }
        return result;
    }
}
```

## 后序遍历

**核心思路：后序是左右中，可以先记录中右左的顺序，再反转数组**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<int> PostorderTraversal(TreeNode root) {
        Stack<TreeNode> stack = new();
        List<int> result = new();
        if (root == null)
            return result;
        stack.Push(root);
        while (stack.Count > 0){
            TreeNode temp = stack.Peek();
            result.Add(stack.Pop().val);
            if (temp.left != null)
                stack.Push(temp.left);
            if (temp.right != null)
                stack.Push(temp.right);
        }
        result.Reverse();
        return result;
    }
}
```

## 中序遍历

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<int> InorderTraversal(TreeNode root) {
        Stack<TreeNode> stack = new();
        List<int> result = new();
        TreeNode cur = root;
        while (cur != null || stack.Count > 0){
            if (cur != null){
                stack.Push(cur);
                cur = cur.left;
            }
            else{
                cur = stack.Peek();
                result.Add(stack.Pop().val);
                cur = cur.right;
            }
        }
        return result;
    }
}
```

## 统一迭代（空指针标记法）

统一前中后序遍历的风格，让其类似递归遍历，可以统一使用

**核心思路：第一次遇到节点（用null占位符判断），展开子树；第二次遇到节点，记录值。**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<int> InorderTraversal(TreeNode root) {
        Stack<TreeNode> stack = new();
        List<int> result = new();
        if (root == null)
            return result;
        stack.Push(root);
        while (stack.Count > 0){
            TreeNode node = stack.Pop();
            if (node == null){
                result.Add(stack.Pop().val);
                continue;
            }
            //不同的序列遍历改变下面的顺序就行
            if (node.right != null) //右
                stack.Push(node.right);
            stack.Push(node); //中
            stack.Push(null);
            if (node.left != null) //左 
                stack.Push(node.left);
        }
        return result;
    }
}
```

## 统一迭代（boolean 标记法）

统一前中后序遍历的风格，让其类似递归遍历，可以统一使用

**核心思路：第一次遇到节点（用bool值判断），展开子树；第二次遇到节点，记录值。**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<int> InorderTraversal(TreeNode root) {
        Stack<(TreeNode, bool)> stack = new();
        List<int> result = new();
        if (root == null)
            return result;
        stack.Push((root, false));
        while (stack.Count > 0){
            (TreeNode, bool) node = stack.Pop();
            if (node.Item2){
                result.Add(node.Item1.val);
                continue;
            }
            if (node.Item1.right != null)
                stack.Push((node.Item1.right, false));
            node = (node.Item1, true);
            stack.Push(node);
            if (node.Item1.left != null)
                stack.Push((node.Item1.left, false));
        }
        return result;
    }
}
```

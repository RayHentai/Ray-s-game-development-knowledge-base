## 题目描述

给定一个不重复的整数数组 `nums` 。 **最大二叉树** 可以用下面的算法从 `nums` 递归地构建:

1. 创建一个根节点，其值为 `nums` 中的最大值。
2. 递归地在最大值 **左边** 的 **子数组前缀上** 构建左子树。
3. 递归地在最大值 **右边** 的 **子数组后缀上** 构建右子树。

返回 _`nums` 构建的_ **_最大二叉树_** 。

**示例 1：**
![[最大二叉树 图示1.png|176]]

**输入：** nums = \[3,2,1,6,0,5]
**输出：** \[6,3,5,null,2,0,null,null,1]
**解释：** 递归调用如下所示：
- \[3,2,1,6,0,5] 中的最大值是 6 ，左边部分是 \[3,2,1] ，右边部分是 \[0,5] 。
    - \[3,2,1] 中的最大值是 3 ，左边部分是 \[] ，右边部分是 \[2,1] 。
        - 空数组，无子节点。
        - \[2,1] 中的最大值是 2 ，左边部分是 \[] ，右边部分是 \[1] 。
            - 空数组，无子节点。
            - 只有一个元素，所以子节点是一个值为 1 的节点。
    - \[0,5] 中的最大值是 5 ，左边部分是 \[0] ，右边部分是 \[] 。
        - 只有一个元素，所以子节点是一个值为 0 的节点。
        - 空数组，无子节点。

**输出：**\[3,null,2,null,1]

## 解法一：递归法

**思路：**

**时间复杂度：** O(n²) 寻找最大值n，递归n次
**空间复杂度：** O(n)

```csharp
public class Solution {
    public TreeNode ConstructMaximumBinaryTree(int[] nums) {
        return Binary(0, nums.Length - 1);
        TreeNode Binary(int left, int right){
            int maxIndex = left;
            if (left > right)
                return null;
            for (int i = left; i <= right; i++) //找最大值索引
                if (nums[i] > nums[maxIndex])
                    maxIndex = i;
            TreeNode root = new TreeNode(
                nums[maxIndex],
                Binary(left, maxIndex - 1),
                Binary(maxIndex + 1, right)
            );
            return root;
        }
    }
}
```

## 解法二：单调栈（最优）

**核心思路：**

维护一个单调递减的栈，遍历数组时对每个元素：
- 如果当前元素比栈顶小，当前元素是栈顶的右子节点
- 如果当前元素比栈顶大，弹出栈顶，弹出的元素成为当前元素的左子节点，继续和新栈顶比较
- 最后栈底就是根节点

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public TreeNode ConstructMaximumBinaryTree(int[] nums) {
        if (nums.Length == 0)
            return null;
        Stack<TreeNode> stack = new();
        TreeNode popped = new();
        for (int i = 0; i < nums.Length; i++){
            TreeNode cur = new(nums[i]);
            while (stack.Count > 0 && stack.Peek().val < cur.val){
                popped = stack.Pop();
                cur.left = popped;
            }
            if (stack.Count > 0)
                stack.Peek().right = cur;
            stack.Push(cur);
        }
        return stack.Last();
    }
}
```

## 题目描述

给你一个二叉树的根节点 `root` ，按 **任意顺序** ，返回所有从根节点到叶子节点的路径。

## 解法一：递归

**思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<string> BinaryTreePaths(TreeNode root) {
        string path = "";
        List<string> result = new();
        traversal(root, path);
        void traversal(TreeNode root, string path){
            if (root == null)
                return;
            path += root.val;
            if (root.left == null && root.right == null){
                result.Add(path);
            }
            else{
                path += "->";
                traversal(root.left, path);
                traversal(root.right, path);
            }
        }
        return result;
    }
}
```

## 解法二：迭代

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public IList<string> BinaryTreePaths(TreeNode root) {
        List<string> result = new();
        if (root == null)
            return result;
        Stack<(TreeNode, string)> stack = new();
        string path = root.val.ToString();
        stack.Push((root, path));
        while (stack.Count > 0){
            (TreeNode, string) nodeMata = stack.Pop();
            TreeNode node = nodeMata.Item1;
            if (node.left == null && node.right == null)
                result.Add(nodeMata.Item2);
            if (node.left != null)
                stack.Push((node.left, nodeMata.Item2 + "->" + node.left.val));
            if (node.right != null)
                stack.Push((node.right, nodeMata.Item2 + "->" + node.right.val));
        }
        return result;
    }
}
```

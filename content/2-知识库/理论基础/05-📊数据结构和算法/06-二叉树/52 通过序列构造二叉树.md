## 题目描述

给定两个整数数组 `inorder` 和 `postorder` ，其中 `inorder` 是二叉树的中序遍历， `postorder` 是同一棵树的后序遍历，请你构造并返回这颗 _二叉树_ 。

**示例 1:**
![[通过中序和后序序列构造二叉树 图示.png|166]]

**输入：** inorder = \[9,3,15,20,7], postorder = \[9,15,7,20,3]
**输出：**\[3,9,20,null,null,15,7]

**示例 2:**

**输入：** inorder = \[-1], postorder = \[-1]
**输出：**\[-1]

给定两个整数数组 `preorder` 和 `inorder` ，其中 `preorder` 是二叉树的**先序遍历**， `inorder` 是同一棵树的**中序遍历**，请构造二叉树并返回其根节点。

## 中序与后序：暴力解法

**思路：后序的最后一个元素可以得到根节点、有了根节点就可以从中序中筛选出左右子树，然后通过数组切片继续跟节点的左右子树赋值即可。**
![[通过序列构造二叉树的思路 图示.png|502]]
**时间复杂度：** O(n²) IndexOf n、切片创建新数组n、递归深度n
**空间复杂度：** O(n²) 递归栈n、每次递归新建新数组n

```csharp
public class Solution {
    public TreeNode BuildTree(int[] inorder, int[] postorder) {
        if (inorder.Length == 0 && postorder.Length == 0)
            return null;
        int rootValue = postorder.Last();
        TreeNode root = new(rootValue);
        int rootIndex = Array.IndexOf(inorder, rootValue);
        root.left = BuildTree(inorder[..rootIndex], postorder[..rootIndex]);
        root.right = BuildTree(inorder[(rootIndex + 1)..], postorder[rootIndex..(inorder.Length - 1)]);
        return root;
    }
}
```

## 中序与后序：性能优化（最优）

**核心思路：**
1. 第一步：用 Dictionary 避免IndexOf重复查找
2. 第二步：用索引范围避免切片，通过辅助函数Build实现，每次递归就不用生成新数组

用空间换时间，预存索引让查找从 O(n) 降到 O(1)，这是哈希表的经典应用。
**原地操作**或者**双指针/索引边界**，本质是用索引代替切片，避免额外内存分配。

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public TreeNode BuildTree(int[] inorder, int[] postorder) {
        Dictionary<int, int> indexMap = new();
        for (int i = 0; i < inorder.Length; i++)
            indexMap[inorder[i]] = i;
        return Build(0, inorder.Length - 1, 0, postorder.Length - 1);

        TreeNode Build(int inLeft, int inRight, int postLeft, int postRight){
            if (inLeft > inRight) //终止条件 如果数组为空，right传进来就会是-1
                return null;
            int rootValue = postorder[postRight];//取根节点值
            int rootIndex = indexMap[rootValue];//取根节点索引
            int leftTreeLong = rootIndex - inLeft;//左子树长度
            TreeNode root = new
            (
			    rootValue, 
				Build(inLeft, rootIndex - 1, postLeft, postLeft + leftTreeLong - 1),
			    Build(rootIndex + 1, inRight, postLeft + leftTreeLong, postRight - 1)
			);
            return root;
        }
    }
}
```

## 解法三：中序与前序：（最优）

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public TreeNode BuildTree(int[] preorder, int[] inorder) {
        Dictionary<int, int> indexMap = new();
        for (int i = 0; i < inorder.Length; i++)
            indexMap[inorder[i]] = i;
        return Build(0, inorder.Length - 1, 0, preorder.Length - 1);

        TreeNode Build(int inLeft, int inRight, int pretLeft, int pretRight){
            if (inLeft > inRight)
                return null;
            int rootValue = preorder[pretLeft];
            int rootIndex = indexMap[rootValue];
            int leftTreeLong = rootIndex - inLeft;
            TreeNode root = new(
                rootValue,
                Build(inLeft, rootIndex - 1, pretLeft + 1, pretLeft + leftTreeLong),
                Build(rootIndex + 1, inRight, pretLeft + 1 + leftTreeLong, pretRight)
            );
            return root;
        }
    }
}
```

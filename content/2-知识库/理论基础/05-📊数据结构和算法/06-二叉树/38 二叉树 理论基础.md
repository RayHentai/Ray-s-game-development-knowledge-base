## 核心理解

树是一种数据结构，它是由n（n>=1）个有限节点组成一个具有层次关系的集合

二叉树是每个节点最多有两个子树的树结构

---

## 二叉树的种类

---
### 没有数值的

---

#### 满二叉树

如果一棵二叉树只有度为0的结点和度为2的结点，并且度为0的结点在同一层上，则这棵二叉树为满二叉树
一个结点有几个子结点就是几度

这棵二叉树为满二叉树，也可以说深度为k，有2^k-1个节点的二叉树

![[满二叉树 图示.png|311]]

---

#### 完全二叉树

在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。
若最底层为第 h 层（h从1开始），则该层包含 1~ 2^(h-1) 个节点

**堆就是一棵完全二叉树，同时保证父子节点的顺序关系。**
![[完全二叉树 图示.png|528]]

---

### 有数值的

---

#### 二叉搜索树

若它的左子树不空，则左子树上所有结点的值均小于它的根结点的值；
若它的右子树不空，则右子树上所有结点的值均大于它的根结点的值；
它的左、右子树也分别为二叉排序树

![[二叉搜索树 图示.png|505]]

---

#### 平衡二叉搜索树

又被称为AVL（Adelson-Velsky and Landis）树
具有以下性质：它是一棵空树或它的左右两个子树的高度差的绝对值不超过1，并且左右两个子树都是一棵平衡二叉树。

## 二叉树的遍历方式

**1. 深度优先遍历：先往深走，遇到叶子节点再往回走。**
- 前序遍历（递归法，迭代法）
- 中序遍历（递归法，迭代法）
- 后序遍历（递归法，迭代法）

**前中后，其实指的就是中间节点（5）的遍历顺序**

![[二叉树深度优先遍历 图示.png|619]]

---

**2. 广度优先遍历：一层一层的去遍历。**
- 层次遍历（迭代法）

广度优先遍历的实现一般使用队列来实现，这也是队列先进先出的特点所决定的，因为需要先进先出的结构，才能一层一层的来遍历二叉树。

**遍历二叉树是栈与队列的一个应用场景。**

### 深度优先遍历：先往深走，遇到叶子节点再往回走。

---

#### 递归遍历

**每次写递归，按照三要素来写！**

1. **确定递归函数的参数和返回值：** 确定哪些参数是递归的过程中需要处理的，那么就在递归函数里加上这个参数， 并且还要明确每次递归的返回值是什么进而确定递归函数的返回类型。

2. **确定终止条件：** 写完了递归算法, 运行的时候，经常会遇到栈溢出的错误，就是没写终止条件或者终止条件写的不对，操作系统也是用一个栈的结构来保存每一层递归的信息，如果递归没有终止，操作系统的内存栈必然就会溢出。

3. **确定单层递归的逻辑：** 确定每一层递归需要处理的信息。在这里也就会重复调用自己来实现递归的过程。

---

需求：二叉树的前序遍历、二叉树的中序遍历、二叉树的后序遍历

声明一个递归方法
确定递归函数的参数和返回值：根节点，无返回值
确定终止条件：根节点为空
确定单层递归的逻辑：将当前节点值添加至数组中

```
result = new List<int>();
traversal(root);
traversal(TreeNode root)
{
	if root == null
		return;
	
	//前中后序只需要更改下面三行代码的顺序
	//前序
	result.Add(root.val)
	traversal(root.left)
	traversal(root.right)
	
	//中序
	traversal(root.left)
	result.Add(root.val)
	traversal(root.right)
	
	//后序
	traversal(root.left)
	traversal(root.right)
	result.Add(root.val)
}
```

#### 递归迭代

空指针标记法

需求：二叉树的前序遍历、二叉树的中序遍历、二叉树的后序遍历

数据结构选用栈
开始遍历前首先判空，给定节点为空直接 `return result`
把根节点压入栈
while循环遍历栈 条件 `stack.Count > 0`
首先记录当前的节点 `node = stack.Pop()`

入栈逻辑，改变入栈逻辑顺序代表不同序的遍历
如果 `node.left != null` `node.left`入栈
`node`入栈，同时入栈一个 `null` 占位，表示该节点已经记录过
如果 `node.right != null` `node.right`入栈

最后在入栈逻辑前加入判断，排除掉有 `null` 占位的重复节点，记录到result中
如果 `node == null` `result.Add(stack.Pop().val)` `continue`

出循环 `return resule`

```
stack = new Stack<TreeNode>()
result = new List<int>()
if root == null
	return result
stack.Push(root)
while stack.Count > 0
	node = stack.Pop()
	if node == null
		result.Add(stack.Pop().val)
		continue
	
	//前中后序只需要更改下面三行代码的顺序 注意！！！！ 栈是先进后出，所以顺序要颠倒
	//前序 右左中
	if node.right != null
		stack.Push(node.right)
	if node.left != null
		stack.Push(node.left)
	stack.Push(node)
	stack.Push(null)
	
	//中序 右中左
	if node.right != null
		stack.Push(node.right)
	stack.Push(node)
	stack.Push(null)
	if node.left != null
		stack.Push(node.left)
	
	//后序 中右左
	stack.Push(node)
	stack.Push(null)
	if node.right != null
		stack.Push(node.right)
	if node.left != null
		stack.Push(node.left)

return result
```

```
result = new List<IList<int>>();
traversal(root)
return result
traversal(TreeNode root, int depth = 0)
{
	if root == null
		return
	if result.Count == depth
		result.Add(new List<int>())
	result[depth].Add(root.val)
	traversal(root.left, depth + 1)
	traversal(root.right, depth + 1)
}
```

#### 迭代遍历

需求：二叉树的层序遍历、二叉树的层序遍历 II、二叉树的右视图、二叉树的层平均值、在每个树行中找最大值、填充每个节点的下一个右侧节点指针、填充每个节点的下一个右侧节点指针 II、二叉树的最大深度、二叉树的最小深度

数据结构选用队列，先进先出
先判空，如果根节点为空，直接 `return result`

入队根节点
while循环遍历，条件为 `queue.Count > 0`
声明需要的变量：当前队列大小、当前根节点、容器

进入for循环 范围`[0, 当前队列大小)`
出队，记录当前节点，将当前节点值加入队列
如果当前节点左节点不为空，入队左节点
如果当前节点右节点不为空，入队右节点

出for循环，将容器添加至 `result`

出while循环`return result`

```
result = new List<IList<int>>()
if root == null
	return result
queue = new Queue<TreeNode>()
queue.Enqueue(root)
while queue.Count > 0
	index = queue.Count
	TreeNode node
	list = new List<int>
	for i = 0; i < index; i++
		node = queue.Dequeue()
		list.Add(node.val)
		if node.left != null
			queue.Enqueue(node.left)
		if node.right != null
			queue.Enqueue(node.right)
	result.Add(list)
return result
```

### 构造树

必须已知中序数组，以及后续或者前序的任意一个数组，就可以构造二叉树

以已知中序、后序为例

中序的顺序是 左 中 右
后序的顺序是 左 右 中

那么根节点就是后序的最后一位，取出来
然后通过 `IndexOf` 得到 根节点 `val` 在中序数组中的顺序

执行树的构造函数，将当前节点值，左节点（递归）、右节点（递归）作为参数传入，左右节点的递归函数需要进行数组切片，更新数组的范围
`return` 构造好的节点

`IndexOf` 和 数组切片 会让函数时间空间复杂度都来到 `n²` 可以在此基础上优化

`Dictionary` 可以将查找索引降至O(n)
辅助函数可以避免切片不断重新生成数组

声明一个 `Dictionary` ，中序数组的值作为键，索引作为值
声明一个辅助函数，返回值树节点，传入两个数组的范围，来进行中序、后序数组索引范围的取值

执行辅助函数，参数为0、中序数组的长度 - 1、0、后序数组的长度 - 1

辅助函数中
- 传入参数：中序数组起始索引、中序数组结束索引、后序数组起始索引、后序数组结束索引
- 终止条件：任意数组的左边界大于右边界，因为数组为空时右边界会= -1
- 单层逻辑：
	- 找到根节点，找到根节点的索引值，找到根节点左分支节点数量
	- 声明新节点，传入根节点值、左节点（递归）、右节点（递归）
	- 返回根节点

关于递归函数传入的参数，应该是子树对应的索引范围
- 左节点：中序数组起始索引, 左分支节点数量 - 1, 后序数组起始索引, 后序数组起始索引 + 左分支节点数量 - 1
- 右节点：根节点的索引值 + 1, 中序数组结束索引, 后序数组起始索引 + 左分支节点数量, 后序数组结束索引 - 1

```
Dictionary<int, int> indexMap = new();
for i = 0; i < inorder.Length; i++
	indexMap[inorder[i]] = i;
return Build(0, inorder.Length - 1, 0, postorder.Length - 1);

TreeNode Build(int inLeft, int inRight, int postLeft, int postRight)
{
	if inLeft > inRight //终止条件
		return null
	int rootValue = postorder[postRight] //取根节点值
	int rootIndex = indexMap[rootValue] //取根节点索引
	int leftTreeLong = rootIndex - inLeft //左子树长度
	TreeNode root = new
	(
		rootValue, 
		Build(inLeft, rootIndex - 1, postLeft, postLeft + leftTreeLong - 1),
		Build(rootIndex + 1, inRight, postLeft + leftTreeLong, postRight - 1)
	)
	return root
}
```

### 双指针

需求：填充每个节点的下一个右侧节点指针

声明两个指针，一个代表每一层的头节点的levelStart，一个代表当前层的第几个元素的cur
两层while循环 第一层移动层头节点指针，一层移动层节点指针
外层条件 `levelStart != null && levelStart.left != null`
内层条件 `cur != null`
内层需要处理的事情
改变 `left.next `
改变 `right.next` 只有 `cur.next != null` 满足才执行
让`cur = cur.next`

出内层循环
移动 `levelStart` `levelStart = levelStart.left`
重置 `cur` `cur = levelStart`

出外层循环 `return root`

```
levelStart = root
cur = root
while levelStart != null && levelStart.left != null
	while cur != null
		cur.left.next = cur.right
		if cur.next != null
			cur.right.next = cur.next.left
		cur = cur.next
	levelStart = levelStart.left
	cur = levelStart
return root
```

## 二叉树的最大深度（迭代法）

**思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public int MaxDepth(TreeNode root) {
        int Depth = 0;
        if (root == null)
            return Depth;
        Queue<TreeNode> queue = new();
        queue.Enqueue(root);
        while (queue.Count > 0){
            int index = queue.Count;
            for (int i = 0; i < index; i++){
                TreeNode node = queue.Dequeue();
                if (node.left != null)
                    queue.Enqueue(node.left);
                if (node.right != null)
                    queue.Enqueue(node.right);
            }
            ++Depth;
        }
        return Depth;
    }
}
```

## 二叉树的最大深度（递归法）

**核心思路：**

**时间复杂度：** O()
**空间复杂度：** O()

```csharp
public class Solution {
    public int MaxDepth(TreeNode root) {
        if (root == null)
            return 0;
        return Math.Max(MaxDepth(root.left), MaxDepth(root.right)) + 1;
    }
}
```

## N叉树的最大深度（迭代法）

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public int MaxDepth(Node root) {
        int depth = 0;
        if (root == null)
            return depth;
        Queue<Node> queue = new();
        queue.Enqueue(root);
        while (queue.Count > 0){
            int index = queue.Count;
            for (int i = 0; i < index; i++){
                Node node = queue.Dequeue();
                for (int j = 0; j < node.children.Count; j++)
                    queue.Enqueue(node.children[j]);
            }
            ++depth;
        }
        return depth;
    }
}
```

## N叉树的最大深度（递归法）

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public int MaxDepth(Node root) {
        int depth = 0;
        if (root == null)
            return depth;
        for (int i = 0; i < root.children.Count; i++)
            depth = Math.Max(depth, MaxDepth(root.children[i]));
        return depth + 1;
    }
}
```

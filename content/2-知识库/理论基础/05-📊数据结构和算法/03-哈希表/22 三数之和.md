## 题目描述

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

**注意：** 答案中不可以包含重复的三元组。

**示例 1：**
**输入：** nums = \[-1,0,1,2,-1,-4]
**输出：** \[\[-1,-1,2],\[-1,0,1]]
**解释：**
nums\[0] + nums\[1] + nums\[2] = (-1) + 0 + 1 = 0 。
nums\[1] + nums\[2] + nums\[4] = 0 + 1 + (-1) = 0 。
nums\[0] + nums\[3] + nums\[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 \[-1,0,1] 和 \[-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。

**示例 2：**
**输入：** nums = \[0,1,1]
**输出：**\[]
**解释：** 唯一可能的三元组和不为 0 。

**示例 3：**
**输入：** nums = \[0,0,0]
**输出：**\[\[0,0,0]]
**解释：** 唯一可能的三元组和为 0 。

## 解法一：排序+双指针法

**思路：先排序让数组有序，然后固定一个数，用对撞指针在剩余范围内找另外两个数**

**时间复杂度：** O(n²)
**空间复杂度：** O(1)、如果算排序的话O(log n)

```csharp
public class Solution {
    public IList<IList<int>> ThreeSum(int[] nums) {
        List<IList<int>> resultList = new List<IList<int>>();
        int leftCur = 0;
        int rightCur = 0;
        Array.Sort(nums);
        for (int i = 0; i < nums.Length; i++){
	        if (nums[i] > 0) //剪枝
		        break;
            if (i > 0 && nums[i] == nums[i - 1])
                continue;
            leftCur = i + 1;
            rightCur = nums.Length - 1;
            while (leftCur < rightCur){
                if (nums[i] + nums[leftCur] + nums[rightCur] > 0)
                    --rightCur;
                else if (nums[i] + nums[leftCur] + nums[rightCur] < 0)
                    ++leftCur;
                else{
                    List<int> list = new List<int>() {nums[i], nums[leftCur], nums[rightCur]};
                    resultList.Add(list);
                    while (leftCur < rightCur && nums[leftCur] == nums[leftCur + 1])
                        ++leftCur;
                    while (leftCur < rightCur && nums[rightCur] == nums[rightCur - 1])
                        --rightCur;
                    ++leftCur;
                    --rightCur;
                }
            }
        }
        return resultList;
    }
}
```

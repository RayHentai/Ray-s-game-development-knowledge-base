## 题目描述

编写一个算法来判断一个数 `n` 是不是快乐数。

**「快乐数」** 定义为：
- 对于一个正整数，每一次将该数替换为它每个位置上的数字的平方和。
- 然后重复这个过程直到这个数变为 1，也可能是 **无限循环** 但始终变不到 1。
- 如果这个过程 **结果为** 1，那么这个数就是快乐数。

如果 `n` 是 _快乐数_ 就返回 `true` ；不是，则返回 `false` 。

**示例 1：**

**输入：** n = 19
**输出：** true
**解释：**
12 + 92 = 82
82 + 22 = 68
62 + 82 = 100
12 + 02 + 02 = 1

**示例 2：**

**输入：** n = 2
**输出：** false

## 解法一：哈希表法

**思路：外层循环排除满足条件的情况，内层循环用HashSet找到无限循环的情况**

**时间复杂度：** O(log n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public bool IsHappy(int n) {
        int sum = 0;
        int num = 0;
        HashSet<int> set = new HashSet<int>();
        while (sum != 1){
            sum = 0;
            while(n != 0){
                num = n % 10;
                sum += num * num;
                n = n / 10;
            }
            n = sum;
            if (set.Contains(sum))
                    return false;
            set.Add(sum);
        }
        return true;
    }
}
```

## 解法二：快慢指针

**核心思路：把求和的结果模拟成循环链表，快指针就是每次求和2次，慢指针1次，两个指针最终会相遇，要么是在1处相遇（快乐数），要么是在非1的指针相遇（非快乐数）**

**时间复杂度：** O(log n)
**空间复杂度：** O(1)

```csharp
public class Solution {
    public bool IsHappy(int n) {
        int slowCur = n;
        int fastCur = GetSum(n);
        while(fastCur != slowCur){
            slowCur = GetSum(slowCur);
            fastCur = GetSum(GetSum(fastCur));
        }
        return fastCur == 1;
    }
    public int GetSum(int num){
        int sum = 0;
        while(num != 0){
            sum += (num % 10) * (num % 10);
            num /= 10;
        }
        return sum;
    }
}
```

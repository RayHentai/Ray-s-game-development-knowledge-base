## 题目描述

给你四个整数数组 `nums1`、`nums2`、`nums3` 和 `nums4` ，数组长度都是 `n` ，请你计算有多少个元组 `(i, j, k, l)` 能满足：

- `0 <= i, j, k, l < n`
- `nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0`

**示例 1：**

**输入：** nums1 = \[1,2], nums2 = \[-2,-1], nums3 = \[-1,2], nums4 = \[0,2]
**输出：** 2
**解释：**
两个元组如下：
1. (0, 0, 0, 1) -> nums1\[0] + nums2\[0] + nums3\[0] + nums4\[1] = 1 + (-2) + (-1) + 2 = 0
2. (1, 1, 0, 0) -> nums1\[1] + nums2\[1] + nums3\[0] + nums4\[0] = 2 + (-1) + (-1) + 0 = 0

**示例 2：**

**输入：** nums1 = \[0], nums2 = \[0], nums3 = \[0], nums4 = \[0]
**输出：** 1

## 解法一：分组哈希法

**思路：先用字典存前两个数组元素的和，以及该和的出现次数，然后再计算后两个数组的和，判断前面记录的字典中有没有Key 为 -和的元素，有则结果计数+1**

**时间复杂度：** O(n²)
**空间复杂度：** O(n²)

```csharp
public class Solution {
    public int FourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        Dictionary<int, int> dic12 = new Dictionary<int, int>();
        int sum12 = 0;
        int sum34 = 0;
        int count = 0;
        for (int i = 0; i < nums1.Length; i++){
            for (int j = 0; j < nums1.Length; j++){
                sum12 = nums1[i] + nums2[j];
                if (dic12.ContainsKey(sum12))
                    ++dic12[sum12];
                else
                    dic12.Add(sum12, 1);
                sum12 = 0;
            }
        }
        for (int i = 0; i < nums3.Length; i++){
            for (int j = 0; j < nums4.Length; j++){
                sum34 = nums3[i] + nums4[j];
                if (dic12.ContainsKey(-sum34))
                    ++count;
            }
        }
        return count;
    }
}
```

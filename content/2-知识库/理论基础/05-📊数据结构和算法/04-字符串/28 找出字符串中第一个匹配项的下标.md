## 题目描述

给你两个字符串 `haystack` 和 `needle` ，请你在 `haystack` 字符串中找出 `needle` 字符串的第一个匹配项的下标（下标从 0 开始）。如果 `needle` 不是 `haystack` 的一部分，则返回  `-1` 。

**示例 1：**

**输入：** haystack = "sadbutsad", needle = "sad"
**输出：** 0
**解释：**"sad" 在下标 0 和 6 处匹配。
第一个匹配项的下标是 0 ，所以返回 0 。

**示例 2：**

**输入：** haystack = "leetcode", needle = "leeto"
**输出：**-1
**解释：**"leeto" 没有在 "leetcode" 中出现，所以返回 -1 。

## 解法二：KMP算法（最优）

**核心思路：用 next 数组存储前缀表，前缀表记录的是每个位置结尾的子串中最长相等前后缀的长度。匹配失败时无需从头开始，只需将 needle 指针回退到 `next[j-1]`，即前缀结束之后的位置继续比较。**

**时间复杂度：** O(m + n)
**空间复杂度：** O(1)

```csharp
public class Solution {
    public int StrStr(string haystack, string needle) {
        int[] next = new int[needle.Length];
        int slow = 0;
        for (int fast = 1; fast < needle.Length; fast++){
            while (slow != 0 && needle[fast] != needle[slow])
                slow = next[slow - 1];
            if (needle[fast] == needle[slow])
                next[fast] = ++slow;
        }

        int needleCur = 0;
        for (int haystackCur = 0; haystackCur < haystack.Length; haystackCur++){
            while (needleCur != 0 && haystack[haystackCur] != needle[needleCur])
                needleCur = next[needleCur - 1];
            if (haystack[haystackCur] == needle[needleCur])
                ++needleCur;
            if (needleCur == needle.Length)
                return haystackCur - needleCur + 1;
        }
        return -1;
    }
}
```

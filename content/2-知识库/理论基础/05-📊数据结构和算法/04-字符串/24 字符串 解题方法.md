## 双指针

快慢指针、对撞指针
需求：反转字符串

for循环，声明左右指针，调换指针元素位置

```
for left = 0, right = Length - 1; left < right; left++, right--
	(s[left], s[right]) = (s[right], s[left])
```

对撞指针

需求：反转字符串中的单词

该方法用纯指针进行移动操作，在字符串可变的语言中可以将空间复杂度降至O(1)

**1. 首先用快慢指针剔除首尾多余空格**
for循环 条件为 `fast < Length`
为慢指针赋值 `slow = 0`
有两种情况
快指针索引对应的值为空 `c[fast] == ' '` 并且 慢指针前一个索引对应的值不为空 `s[slow - 1] != ' '` 并且 慢指针 > 0 不然会越界 `slow > 0`
慢指针写入一个空格，并移动指针 `c[slow++] = ' '`

快指针索引对应的值不为空 `c[fast] != ' '`
慢指针写入快指针的值，并移动指针 `c[slow++] = c[fast]`

**2. 其次反转整个字符串**
先移除字符串尾部空格，重新赋值就行 `c = c[..slow]`
反转 `c.Reverse()`

**3. 最后反转单词**
for循环，范围`[left, Length)`
定位right 先给right赋值 如果 `c[left] != ' '` `right = left`
while循环 定位 right，条件 `right < Length` 并且 `c[right] != ' '` `++right`

反转 这个区间的单词 `c[left..right].Reverse()`
更新left `left = right`

**4. 优化补充边界**
第一步如果最后一个写入的字符是空格，慢指针会往后面移动一位，会残留一个空格
在反转整个字符串前加入一个判断条件就行
如果 `slow > 0` 并且 `c[slow - 1] == ' '` `--slow`

```
Span<char> c = s.ToCharArray().AsSpan();
slow = 0;
for fast = 0; fast < Length; fast++
	if c[fast] == ' ' && c[slow - 1] != ' ' && slow > 0
		c[slow++] = ' '
	else if c[fast] != ' '
		c[slow++] = c[fast]
if slow > 0 && c[slow - 1] == ' '
	--slow
	
c = c[..slow]
c.Reverse()

for left = 0; left < Length; left++
	if c[left] != ' '
		right = left
		while right < Length && c[right] != ' '
			++right
		c[left..right].Reverse()
		left = right
return c.ToString()
```

## 模拟

需求：反转字符串Ⅱ

和反转字符串不同的是，每2k个字符反转前k个字符，让for循环每次移动2k步长，然后进行处理逻辑就行

进入for循环，范围 `[0, Length)` ，每次进入循环增加2k
循环内 反转该区间前k个字符，右边界需要进行边界判断，不能大于最大索引
用目标语言的方法反转该范围的字符串即可

出循环 `return` 修改后的字符串

```
span = s.ToCharArray().AsSpan();
for i = 0; i < Length; i += 2k
	span[i + k > Length ? i.. : i..(i + k)].Reverse()
return span.ToString()
```

用目标语言提供的API
需求：反转字符串中的单词

先去掉首尾空格，再按照空格拆分单词并且去掉所有空格，再反转组合，再用空格拼接组合

直接用string自带的方法
第一步 去首尾空格 Trim
第二步 按照空格拆分单词并去掉空格 Split

直接 `return` 处理后的字符串

```
return String.Join(" ", s.Trim().Split(' ', StringSplitOptions.RemoveEmptyEntries).Reverse());
```

## 移动匹配

需求：重复的子字符串

把两个字符串拼接成新字符串 `ss = s + s`
掐头去尾新字符串
再用新字符串去匹配字符串，如果包含完整字符串则说明该字符串由重复字符串组成

```
ss = s + s
ss = ss[1..^1];
return ss.Contains(s);
```

## KMP算法

KMP主要应用在字符串匹配上

KMP的主要思想是：**当出现字符串不匹配时，可以知道一部分之前已经匹配的文本内容，可以利用这些信息避免从头再去做匹配。**

---

**前缀表 next 数组**

**前缀表是用来回退的，它记录了模式串与主串(文本串)不匹配的时候，模式串应该从哪里开始重新匹配。**

<iframe src="file:///D:/OneDrive/文档/Obsidian/Hentai的知识库\4-归档\HTML\next数组构建.html" width="100%" height="750px" style="border:none;"></iframe>

`next[i]` 存的是以 `i` 结尾的子串中，最长相等前后缀的长度。

比如 s = 'aaabaaa' 
假设i为4，当前记录字符串为 'aaaba' `next[4]`就等于 1 ('aaaba' 相同前缀后缀为'a' 长度为1)
假设i为6，当前记录字符串为 'aaabaaa' `next[6]`就等于 3 ('aaabaaa' 相同前缀后缀为'aaa' 长度为3)

匹配字符串的时候，如果匹配失败，就让模式串的指针回退到next对应的索引重新匹配即可，相当于跳过了已经匹配过的前缀，无需跳到开头。字符串也无需移动，待模式串回退完继续匹配即可。

![[前缀表原理 图示.gif|297]]

next 数组是 KMP 的核心，它提前记录了 needle 自身的规律，使得匹配失败时不需要从头重来，而是查 `next[j-1]` 直接跳到正确位置。没有 next 数组，KMP 就退化成暴力匹配。

匹配失败时，needle 指针跳到 `next[j-1]`，含义是：已匹配部分的前缀和后缀重合，前缀已经对齐，从前缀之后继续比就行。

查的是 `next[j-1]` 而不是 `next[j]`，因为 `j` 是已匹配的长度，已匹配部分的最后一个字符下标是 `j-1`。

---

**两段代码的统一结构**

构建 next 数组和匹配 haystack 的逻辑完全对称，都是三步：

1. while 回退到能匹配或退无可退
2. if 匹配成功则推进
3. if 检查终止条件

---

需求：找出字符串中第一个匹配项的下标

**1. 初始化前缀表next数组**
长度为模式串的长度 `next = new int[needle.Length]`

构建next数组，用快慢指针构建
for循环 `fast` 范围取`[1, needle.Length)`

分三种情况
如果快慢指针的值匹配上，前进慢指针，记录next的索引
如果快慢指针的值没有匹配上，并且慢指针 > 0，while循环回退慢指针
如果快慢指针的值没有匹配上，并且慢指针 = 0，无需任何处理

**2. 匹配字符串**
为模式串和字符串声明两个指针
for循环 `haystackCur` 范围取`[0, haystack.Length)`

分两种情况
如果两个指针值匹配成功，一起前进

前进完判断是否完全匹配
如果 模式串指针 == 模式串的长度 则说明匹配成功 `return 索引 `

如果两个指针值匹配失败，并且模式串指针 > 0，while循环回退模式串指针

如果出循环，证明匹配失败，`return -1`

```
next = GetNextArr(needle)
needleCur = 0;
for haystackCur = 0; haystackCur < haystack.Length; haystackCur++
	while needleCur > 0 && needle[needleCur] != haystack[haystackCur] //回退
		needleCur = next[needleCur - 1]
	if needle[needleCur] == haystack[haystackCur]//前进
		++needleCur
	if needleCur >= needle.Length //终止
		return haystackCur - needleCur + 1
return -1

int[] GetNextArr(str)
{
	next = new int[str.Length]
	slow = 0;
	for fast = 1; fast < str.Length; fast++
		while slow > 0 && str[slow] != str[fast]
			slow = next[slow - 1]
		if str[slow] == str[fast]
			next[fast] = ++slow
	return next
}
```

需求：重复的子字符串

**1. 初始化前缀表next数组**
不再赘述

**2. 判断该字符串是否由重复的模式串组成**
如果 总长度 % 模式串长度 == 0 则说明是，同时排除最长相同前后缀长度 == 0的情况
取出`next[s.Length - 1]` 代表`[0, s.Length)`范围内，最长相同前后缀长度
用总长度 - 最长相同前后缀长度 得到模式串长度
返回判断结果 ``return s.Length % (s.Length - next[s.Length - 1]) == 0 && next[s.Length - 1] != 0``

```
next = GetNextArr(s)
return s.Length % (s.Length - next[s.Length - 1]) == 0 && next[s.Length - 1] != 0

int[] GetNextArr(str)
{
	next = new int[str.Length]
	slow = 0;
	for fast = 1; fast < str.Length; fast++
		while slow > 0 && str[slow] != str[fast]
			slow = next[slow - 1]
		if str[slow] == str[fast]
			next[fast] = ++slow
	return next
}
```

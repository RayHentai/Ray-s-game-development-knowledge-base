## 题目描述

给你一个字符串 `s` ，请你反转字符串中 **单词** 的顺序。

**单词** 是由非空格字符组成的字符串。`s` 中使用至少一个空格将字符串中的 **单词** 分隔开。

返回 **单词** 顺序颠倒且 **单词** 之间用单个空格连接的结果字符串。

**注意：** 输入字符串 `s`中可能会存在前导空格、尾随空格或者单词间的多个空格。返回的结果字符串中，单词间应当仅用单个空格分隔，且不包含任何额外的空格。

**示例 1：**

**输入：** s = "the sky is blue"
**输出：**"blue is sky the"

**示例 2：**

**输入：** s = "  hello world  "
**输出：**"world hello"
**解释：** 反转后的字符串中不能存在前导空格和尾随空格。

**示例 3：**

**输入：** s = "a good   example"
**输出：**"example good a"
**解释：** 如果两个单词间有多余的空格，反转后的字符串需要将单词间的空格减少到仅有一个。

## 解法一：暴力解法

**思路：一步一步模拟，先拆同时去重空字符，再反转，再拼接**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public string ReverseWords(string s) {
        String[] strs = s.Split(' ', StringSplitOptions.RemoveEmptyEntries);
        Array.Reverse(strs);
        s = String.Join(" ", strs);
        return s;
    }
}
```

## 解法二：用纯指针替换字符而非API（最优）

**核心思路：先去重每个单词的头尾空字符只保留一个尾字符，再反转字符串，再利用对撞指针反转字符串中每个单词字符**

**时间复杂度：** O(n)
**空间复杂度：** O(n)、如果是允许修改字符串字符的语言则为O(1)

```csharp
public class Solution {
    public string ReverseWords(string s) {
        Span<char> c = s.ToCharArray().AsSpan();
        int slowCur = 0;
        for (int fastCur = 0; fastCur < s.Length; fastCur++){
            if (c[fastCur] != ' ')
                c[slowCur++] = c[fastCur];
            else if (c[fastCur] == ' ' && slowCur > 0 && c[slowCur - 1] != ' ')
                c[slowCur++] = ' ';
        }
        if (slowCur > 0 && c[slowCur - 1] == ' ')
            slowCur--;
        c = c[..slowCur];
        c.Reverse();
        int right = 0;
        for (int left = 0; left < c.Length; left++){
            if (c[left] != ' '){
                right = left;
                while (right < c.Length && c[right] != ' ')
                    ++right;
                c[left..right].Reverse();
                left = right;
            }
        }
        return c.ToString();
    }
}
```

## 解法三：现代语法的暴力解法

**核心思路：**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public string ReverseWords(string s) {
        return String.Join(" ", s.Trim().Split(' ', StringSplitOptions.RemoveEmptyEntries).Reverse());
    }
}
```

## 我的踩坑记录

- **while条件顺序** 先判断边界 `right < c.Length` 再访问 `c[right]`，顺序反了会越界。
- **末尾残留空格** 去空格后末尾可能还有一个空格，取有效部分前要检查 `c[slowCur-1]` 是否是空格。
- **去空格逻辑** 不能简单删掉所有空格，要保留单词间的单个空格，用快慢指针控制写入时机。

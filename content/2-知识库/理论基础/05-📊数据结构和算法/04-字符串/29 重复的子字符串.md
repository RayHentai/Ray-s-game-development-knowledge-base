## 题目描述

给定一个非空的字符串 `s` ，检查是否可以通过由它的一个子串重复多次构成。

**示例 1:**
**输入:** s = "abab"
**输出:** true
**解释:** 可由子串 "ab" 重复两次构成。

**示例 2:**
**输入:** s = "aba"
**输出:** false

**示例 3:**
**输入:** s = "abcabcabcabc"
**输出:** true
**解释:** 可由子串 "abc" 重复四次构成。 (或子串 "abcabc" 重复两次构成。)

## 解法一：移动匹配

**思路：用两个提供的字符串拼接，然后掐头去尾，如果拼接后的字符串能和提供的字符串匹配就符合条件**

**时间复杂度：** O(n)
**空间复杂度：** 取决于`Contains` 底层实现

```csharp
public class Solution {
    public bool RepeatedSubstringPattern(string s) {
        string ss = s + s; 
        ss = ss[1..^1];
        return ss.Contains(s);
    }
}
```

## 解法二：KMP算法（最优）

**核心思路：用字符串总长度除以next最后一位，也就是最长相等前后缀的长度，能除尽就符合条件**

**时间复杂度：** O(n)
**空间复杂度：** O(n)

```csharp
public class Solution {
    public bool RepeatedSubstringPattern(string s) {
        int[] next = GetNext(s);
            return s.Length % (s.Length - next[s.Length - 1]) == 0 && next[s.Length - 1] != 0;
        int[] GetNext(string s){
            int[] next = new int[s.Length];
            int slow = 0;
            for (int fast = 1; fast < s.Length; fast++){
                while (slow > 0 && s[slow] != s[fast])
                    slow = next[slow - 1];
                if (s[slow] == s[fast])
                    next[fast] = ++slow;
            }
            return next;
        }
    }
}
```

## 核心理解

链表是一种**通过指针串联在一起的线性结构**，每一个节点由两部分组成，
- 一个是数据域
- 一个是指针域（存放指向下一个节点的指针）

最后一个节点的指针域指向null（空指针的意思）。
链表的入口节点称为链表的头结点也就是head。
![[链表 图示.png|364]]

```csharp title:定义
public class Node<T>
{
    // 节点存储的数据
    public T Data { get; set; }
    // 指向下一个节点的引用
    public Node<T> Next { get; set; }
    // 节点的构造函数，用于初始化节点
    public Node(T data)
    {
        Data = data;
        Next = null; // 初始时没有下一个节点，因此设为 null
    }
}
```

## 关键特性

**存储方式：在内存中不是连续分布的**

链表是通过指针域的指针链接在内存中各个节点。
所以链表中的节点在内存中不是连续分布的 ，而是**散乱分布在内存中的某地址上**，分配机制取决于操作系统的内存管理。

### 虚拟头结点

**作用：** 统一处理头节点和普通节点的逻辑，避免对头节点单独做判断

**原理：** 在链表头部新建一个不存储有效数据的虚拟节点，让原来的头节点也有了前驱节点，这样删除、插入等操作对所有节点包括原头节点都能用同一套逻辑处理。最后返回 `dummy.next` 而不是原来的 `head`，因为原头节点可能已经被删除了。

**什么时候用：** 需要对链表头节点做增删操作时，用虚拟头节点可以简化代码。

**1. 移除链表元素**

声明一个虚拟头节点 指向当前链表的头节点 `ListNode dummy = new ListNode(0, head)`
声明一个指针节点 指向虚拟头节点  `ListNode cur = dummy`

遍历指针 ``while (cur.next != null)``

进行判断 
如果指针下一个节点的值等于给定值 `if (cur.next.val == val)`  
指针的下一个节点指向指针的下下个节点 `cur.next = cur.next.next`

否则（不等于给定值）移动指针 `cur = cur.next`

出循环 返回虚拟头节点的下一个节点，即头节点 `return dummy.next`

```
dummy = new ListNode(0, head)
cur = dummy
while (cur.next != null)
	if (cur.next.val == val)
		cur.next = cur.next.next
	else
		cur = cur.next
return dummy.next
```

**2. 设计链表**

**需求：**
1. MyLinkedList() 初始化MyLinkedList对象
2. Get(index) 获取下标索引节点值
3. AddAtHead(val) 将指定值插入头部
4. AddAtTail(val) 将指定值插入尾部
5. AddAtIndex(index, val) 将指定值插入下标索引元素之前，如果等于链表长度则插到末尾
6. DeleteAtIndex(index) 删除指定下标索引

构建 `MyLinkedList` 包含链表节点类
成员变量包括虚拟头节点 `LinkedList dummy`、链表长度 `int size`
成员方法包括所有需求

构造函数初始化 虚拟头节点等于空元素、长度等于0  `dummy = new LinkedList(0)` `size = 0`

Get(index) 获取下标索引节点值
声明指针 `LinkedList cur = dummy`
判断边界，判断下标是否合法，不合法返回 -1 `if (index > size - 1 || index < 0)`  `return -1`
否则，通过指针节点遍历至指定索引链表元素 `for (int i = 0; i <= index; i++)` `cur = cur.next`
在循环外取出对应索引值元素值并返回 `return cur.val`

AddAtHead(val) 将指定值插入头部
声明一个空元素 `LinkedList head = new LinkedList(val)`
将新声明的头节点 `next` 指向当前头节点 `head.next = dummy.next`
将虚拟头节点 `next` 指向新头节点 `dummy.next = head`
更新长度 `++size`

AddAtTail(val) 将指定值插入尾部
遍历至尾部元素，将尾部元素的 next指向新声明的元素
声明空元素 `LinkedList tail = new LinkedList(val)`
声明指针 `LinkedList cur = dummy`
遍历，指针指向尾部元素 `for(int i = 0; i < size; i++)` `cur = cur.next`
出循环，让指针的`next`指向声明的元素 `cur.next = tail`
更新长度 `++size`

AddAtIndex(index, val) 将指定值插入下标索引元素之前，如果等于链表长度则插到末尾，如果 比长度更大，该节点将不会插入到链表中
判断边界，索引必须合法 `if (index < 0 || index > size)` `return`
分情况判断条件 
如果索引等于0，执行 `AddAtHead` : `if (index == 0)` `AddAtHead(val)`
如果所有等于size，执行 `AddAtTail` : `else if (index == size)` `AddAtTail(val)`
否则则正常插入
声明指针、空元素`LinkedList cur = dummy` `LinkedList node = new LinkedList(val)`
遍历至索引前一个元素 `for (int i = 0; i < index; i++)` `cur = cur.next`
出循环 记录当前指针的下一个元素 `LinkedList nowNext = cur.next`
将当前指针元素的 `next` 指向新声明的元素 `cur.next = node`
将新声明的元素的 `next` 指向记录的元素 `node.next = nowNext`
更新长度 `++size`

DeleteAtIndex(index) 删除指定下标索引
判断边界，索引是否合法 `if (index < 0 || index > size - 1)` `return`
声明指针 `LinkedList cur = dummy`
遍历至索引前一个元素 `for (int i = 0; i < index; i++)` `cur = cur.next`
索引前一个元素的 `next` 指向索引下下一个元素 `cur.next = cur.next.next`
更新长度 `--size`

```
MyLinkedList
{
	LinkedList
	{
		int val
		LinkedList next
	}
	
	LinkedList dummy
	int size
	MyLinkedList()
	{
		dummy = LinkedList(0)
		size = 0
	}
	int Get(index)
	{
		LinkedList cur = dummy
		if index > size - 1 || index < 0
			return -1
		for i = 0; i <= index; i++
			cur = cur.next;
		return cur.val
	}
	void AddAtHead(val)
	{
		head = LinkedList(val)
		head.next = dummy.next
		dummy.next = head
		++size
	}
	void AddAtTail(val)
	{
		tail = LinkedList(val)
		LinkedList cur = dummy
		for i = 0; i < size; i++
			cur = cur.next
		cur.next = tail
		++size
	}
	void AddAtIndex(index, val)
	{
		if index < 0 || index > size
			return
		if index == 0
			AddAtHead(val)
		else if index == size
			AddAtTail(val)
		else
			LinkedList cur = dummy 
			node = LinkedList(val)
			for i = 0; i < index; i++
				cur = cur.next
			nowNext = cur.next
			cur.next = node
			node.next = nowNext
			++size
	}
	void DeleteAtIndex(index)
	{
		if index < 0 || index > size - 1
			return
		LinkedList cur = dummy 
		for i = 0; i < index; i++
				cur = cur.next
		cur.next = cur.next.next
		--size
	}
}
```

### 双指针

**需求：反转链表**

声明 `pri` 代表当前元素的上一个元素 `pre = null`
声明 `cur` 代表当前元素 `cur = head`

进入while循环，移动两个指针，并且改变将当前元素的 `next`
当 `cur != null` 时 代表反转完成 `while (cur != null)`
记录当前元素的下一个元素 `temp = cur.next`
`cur` 的 `next` 指向 上一个元素 `pri`  `cur.next = pri`
右移当前元素的上一个元素 `pri = cur`
右移当前元素 `cur = temp`

出循环 返回当前的头节点 `return pri`

```
pri = null
cur = head
while (cur != null)
	temp = cur.next
	cur.next = pri
	pri = cur
	cur = temp
return pri
```

**快慢指针**
需求：删除链表的倒数第N个节点

![[删除链表的倒数第 N 个结点 图示.png|287]]

声明虚拟头节点 `LinkedList dummy = new LinkedList(0, head)`
分别声明快慢指针 `fastCur = dummy` `slowCur = dummy`
快指针先走 n 步 `for (int i = 0; i < n; i++)` `fastCur = fastCur.next`

快指针走完 快慢指针一起走，此时快指针走到尾部，慢指针刚好走到要删除的节点前一个节点
`while (fastCur.next != null)` `fastCur = fastCur.next` `slowCur = slowCur.next`
慢指针的 `next` 指向快指针 `slowCur.next = fastCur.next`

返回头节点 `return dummy.next`

```
LinkedList dummy = new LinkedList(0, head)
fastCur = dummy
slowCur = dummy
for int i = 0; i < n; i++
	fastCur = fastCur.next
while fastCur.next != null
	fastCur = fastCur.next
	slowCur = slowCur.next
slowCur.next = fastCur.next
```

**双指针相遇**

需求：得到两个链表的交点

分别声明AB指针 `curA = headA` `curB = headB`
进入循环 AB指针不相等时一直执行 `while (curA != curB)`
`
AB指针一起走，如果A指针走到最后一个节点，从链表B的头节点重新开始走，B指针同理，直到两指针相等
`curA = curA.next == null ? headB : curA.next`
`curB = curB.next == null ? headA : curB.next`

出循环 返回结果 `return curA`

```
curA = headA
curB = headB
while curA != curB
	curA = curA.next == null ? headB : curA.next
	curB = curB.next == null ? headA : curB.next
return curA
```

### 模拟 

**需求：两两交换链表中的节点**

![[两两交换链表中的节点 图示.png|261]]

模拟这个过程
声明虚拟头节点 `LinkedList dummy = new LinkedList(0, head)`
声明指针 `LinkedList cur = dummy`

进入while循环 进入条件为指针前驱节点不为空 `while (cur.next != null && cur.next.next != null)`
记录第1个元素 `nowCur = cur.next`
记录第3个元素 `nextCur = nowCur.next.next`
让 `dummy` 的 `next` 指向 第2个元素 `cur.next = cur.next.next`
指针前进 `cur = cur.next` 此时指针的位置为1 指向原本的第2个元素
让此时指针的 `next` 指向 原本的第1个元素 `cur.next = nowCur`
指针前进 `cur = cur.next` 此时指针的位置为2 指向原本的第1个元素
让此时指针的 `next` 指向 原本的第3个元素 `cur.next = nextCur`

出循环 返回头节点 `return dummy.next`

```
dummy = new LinkedList(0, head)
cur = dummy
while cur.next != null && cur.next.next != null
	nowCur = cur.next // 1
	nextCur = nowCur.next.next // 3
	cur.next = cur.next.next // dummy -> 2
	cur = cur.next
	cur.next = nowCur // dummy -> 1
	cur = cur.next
	cur.next = nextCur //dummy -> 3
return dummy.next
```

### 长度对齐法

需求：得到两个链表的交点

![[链表相交 图示 1.png|389]]

首先分别得到两个链表的长度
声明A指针 `curA = headA`
声明计数变量 `lengthA`
遍历A指针 并计数 `while (curA != null)` `lengthA++` `curA = curA.next` 
重置A指针 `curA = headA`

链表B的计数同理 `curB = headB` `lengthB 
计数 `while (curB != null)` `lengthB++` `curB = curB.next` 
重置B指针`curB = headB`

计算两者差 `diff = lengthA - lengthB`
大于0则说明A更长，小于0则说明B更长，谁更长谁先走

如果大于0 `if (diff > 0)`
A先走 差值步 `for (int i = 0; i < diff; i++)` `curA = curA.next`

如果小于0 `else`
B先走 差值步 `for (int i = 0; i < -diff; i++)` `curB = curB.next`

此时AB长度对齐了，然后一起走 `while (curA != curB)` `curA = curA.next` `curB = curB.next`

出循环 返回结果 `return curA`

```
curA = headA
curB = headB
lengthA
lengthB
while curA != null
	lengthA++
	curA = curA.next
curA = headA

while curB != null
	lengthB++
	curB = curB.next
curB = headB

diff = lengthA - lengthB
if diff > 0
	for int i = 0; i < diff; i++
		curA = curA.next
else
	for int i = 0; i < -diff; i++
		curB = curB.next

while curA != curB
	curA = curA.next
	curB = curB.next

return curA
```

## 本章的数学公式

头部到环入口的距离 = 相遇点到环入口的距离
**a == c**
所以相遇后，一个指针从头部出发，一个从相遇点出发，同速走，相遇即为环入口。

## 题目描述

给你一个整数数组 `nums`，有一个大小为 `k` 的滑动窗口从数组的最左侧移动到数组的最右侧。你只可以看到在滑动窗口内的 `k` 个数字。滑动窗口每次只向右移动一位。

返回 _滑动窗口中的最大值_ 。

**示例 1：**
**输入：** nums = \[1,3,-1,-3,5,3,6,7], k = 3
**输出：**\[3,3,5,5,6,7]

**解释：**
滑动窗口的位置                最大值
---------------               -----
\[1  3  -1] -3  5  3  6  7       **3**
 1 \[3  -1  -3] 5  3  6  7       **3**
 1  3 \[-1  -3  5] 3  6  7       **5**
 1  3  -1 \[-3  5  3] 6  7       **5**
 1  3  -1  -3 \[5  3  6] 7       **6**
 1  3  -1  -3  5 \[3  6  7]      **7**

**示例 2：**
**输入：** nums = \[1], k = 1
**输出：**\[1]

## 解法一：单调队列（用链表模拟单调队列）

**思路：维护队列的头节点，使头节点永远是最大的，所有新节点添加在队列末尾**

**时间复杂度：** O(n)
**空间复杂度：** O(k)

```csharp
public class Solution {
    public int[] MaxSlidingWindow(int[] nums, int k) {
        LinkedList<int> link = new LinkedList<int>();
        int[] result = new int[nums.Length - k + 1];
        for (int i = 0; i < nums.Length; i++){
            if (link.Count > 0 && link.First.Value + k <= i) //检查过期
                link.RemoveFirst();
            while (link.Count > 0 && nums[link.Last.Value] <= nums[i]) //弹出比新数小的队尾元素
                link.RemoveLast();
            link.AddLast(i);//入队
            if (i >= k - 1) //记录
                result[i - k + 1] = nums[link.First.Value];
        }
        return result;
    }
}
```

## 解法二：封装单调队列（最优）

**核心思路：**

**时间复杂度：** O()
**空间复杂度：** O()

```csharp
public class MyDequeue{
    LinkedList<int> linkedList = new LinkedList<int>();
    public int Max => linkedList.First.Value;
    public void Dequeue(int num){
        if (num == linkedList.First.Value)
            linkedList.RemoveFirst();
    }
    public void Enqueue(int num){
        while (linkedList.Count > 0 && linkedList.Last.Value < num)
            linkedList.RemoveLast();
        linkedList.AddLast(num);
    }
}
public class Solution {
    public int[] MaxSlidingWindow(int[] nums, int k) {
        MyDequeue window = new MyDequeue();
        List<int> list = new List<int>();
        for (int i = 0; i < k; i++)
            window.Enqueue(nums[i]);
        list.Add(window.Max);

        for (int i = k; i < nums.Length; i++){
            window.Dequeue(nums[i - k]);
            window.Enqueue(nums[i]);
            list.Add(window.Max);
        }
        return list.ToArray();
    }
}
```

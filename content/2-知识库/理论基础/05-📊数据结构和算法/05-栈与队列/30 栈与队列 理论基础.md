## 核心理解

队列是先进先出，栈是先进后出。

---

## C#相关

C# 的 `Stack<T>` 底层是数组（`T[]`）。

入栈时如果容量不足会自动扩容，和 `List<T>` 的扩容机制类似，但两者是独立的实现。

`Queue<T>` 同理，实现方式是循环数组，用头尾两个指针来避免每次出队都移动元素。

### 模拟 

需求：用栈实现队列

声明成员变量和初始化成员变量

```
inStack;
outStack;

public MyQueue()
{
	inStack = new Stack<int>();
	outStack = new Stack<int>();
}
```

`push` 方法
直接压入 `inStack` 即可

```
public void Push(x)
{
	inStack.Push(x);
}
```

`pop` 和 `peek` 方法，都需要先将 `inStack` 倒腾至 `outStack` 可以先抽象一个方法
只有 `outStack` 为空的时候才倒腾
倒腾之后的 `outStack` 出栈的顺序相较原本的 `inStack` 就由先进后出变为先进先出
待 `outStack` 再次为空时重新倒腾即可

```
public int Pop()
{
	MoveToOutput()
	return outStack.Pop()
}

public int Peek()
{
	MoveToOutput()
	return outStack.Peek()
}

void MoveToOutput()
{
	if outStack.Count == 0
		foreach int item in inStack
			outStack.Push(item)
		inStack.Clear()
}
```

`empty` 方法
判断两个 `Stack` 是否为空返回即可

```
public bool Empty() => inStack.Count == 0 && outStack.Count == 0;
```

需求：用队列实现栈

声明成员变量和初始化成员变量

```
queue;

public MyStack()
{
	queue = new Queue<int>()
}
```

`push` 方法
直接压入 `queue` 即可

```
public void Push(x)
{
	queue.Enqueue(x)
}
```

`pop` 方法
当前是 `Queue` 存储，`Stack` 的 `pop` 是弹出栈顶，即最后一位。
要用 `Queue` 模拟，就得让最后一位成为首位，需要移动 `Count - 1` 次
移动完毕后执行出队 并 `return` 

```
public int Pop()
{
	for int i = 0; i < queue.Count - 1; i++
		queue.Enqueue(queue.Dequeue())
	return queue.Dequeue()
}
```

`peek` 方法
复用Pop代码 得到队尾并记录
入队队尾
`return` 记录的队尾

```
public int Peek()
{
	last = Pop()
	queue.Enqueue(last)
	return last;
}
```

`empty` 方法
判断 `queue` 是否为空返回即可

```
public bool Empty() => queue.Count == 0;
```

需求：有效的括号

声明 `Stack`
进入for循环 范围为`[0, s.Length)`

两种情况 匹配到左括号、匹配到右括号

如果匹配到左括号，压栈，把对应的右括号压进去
如果匹配到右括号，出栈匹配匹配不上则return `false`

出循环 如果栈为空则匹配完毕，return条件

```
stack = new Stack<char>();
for i = 0; i < s.Length; i++
	switch(s[i])
		case '('
			stack.Push(')')
			break
		case '['
			stack.Push(']')
			break
		case '{'
			stack.Push('}')
			break
		default:
			if stack.Count == 0 || s[i] != stack.Pop()
				return false
			break
return stack.Count == 0;
```

需求：删除字符串中的所有相邻重复项

核心数据结构用 `Stack`
遍历字符串，如果栈顶和当前字符相等，弹出栈顶，如果不相等，压入字符
出循环，反转栈，转数组，`return` 结果

```
stack = new Stack<char>()
stack.Push(s[0])
for i = 1; i < s.Length; i++
	if stack.Peek() == s[i]
		stack.Pop()
	else
		 stack.Push(s[i])
return new String(stack.Reverse().ToArray())
```

需求：逆波兰表达式求值

数据结构选用栈

只会有两种字符，算数符号和数字，所以用 `switch` 处理算术符号的逻辑就行，`default` 执行压入元素的逻辑

`-` 和 `/` 需要单独处理 因为是用栈顶的下一位元素减去栈顶 ，`+` 和 `*` 不受影响

```
stack = new Stack<int>();
for i = 0; i < token.Length; i++
	switch token[i]
		case "+"
			stack.Push(stack.Pop() + stack.Pop())
			braek
		case "-"
			temp = stack.Pop()
			stack.Push(stack.Pop() - temp)
			braek
		case "*"
			stack.Push(stack.Pop() * stack.Pop())
			braek
		case "/"
			temp = stack.Pop()
			stack.Push(stack.Pop() / temp)
			braek
		default
			stack.Push(int.Parse(token[i]))
return stack.Peek()
```

### 单调队列

双端队列（Deque，Double-ended Queue）是一种**两端都可以入队和出队的队列**。

单调队列是一种**特殊的双端队列**，队列内的元素始终保持单调（递增或递减）。

比如
\[1,3,7,9,10]、\[99, 54, 33, 21, 10] 这就是单调队列
\[1, 3, 2] 这就不是单调队列

本质上是一种以空间换时间的思路：用 O(k) 的空间维护一个有序结构，让每次取最大值是 O(1)，而不是每次都遍历窗口里的 k 个元素。

---

需求：滑动窗口最大值

以C#为例
因为C#中没有对应双端队列的数据结构，所以用LinkedList构建一个单调队列
需要有入队和出队的方法、获取最大值（当前队头值）的方法

出队只有一种情况，就是当前队头已经不在滑动窗口的范围，出队队头

入队需要进行判断，如果队尾值大于需要入队的值，队尾出队，待所有满足条件的队尾出队，再队尾入队新值

```
class MyDequeue
{
	LinkedList<int> dequeue = new LinkedList()
	public int GetMax => dequeue.First.Value
	public void Dequeue(int num)
	{
		if num == GetMax
			dequeue.RemoveFirst()
	}
	public void Enqueue(int num)
	{
		while dequeue.Count > 0 && dequeue.Last.Value < num
			dequeue.RemoveLast()
		dequeue.AddLast(num)
	}
}

window = new MyDequeue();
list = new List<int>();
for int i = 0; i < k; i++
	window.Enqueue(nums[i])
list.Add(window.GetMax)

for int i = k; i < nums.Length; i++
	window.Dequeue(nums[i - k])
	window.Enqueue(nums[i])
	list.Add(window.GetMax)
```

### 优先队列（堆）

堆是一种特殊的完全二叉树，分两种：
- **最大堆**：每个节点的值都大于等于它的子节点，根节点是最大值
- **最小堆**：每个节点的值都小于等于它的子节点，根节点是最小值

堆的核心操作：
- 插入：O(log n)
- 取出堆顶：O(log n)
- 查看堆顶：O(1)

C# 中用 `PriorityQueue<TElement, TPriority>` 表示，默认是最小堆，优先级数字越小越先出队。

优先队列即一个由优先级绝对出队顺序的队列

需求：前 K 个高频元素

先声明字典，遍历数组，记录频率
再声明最小堆优先队列，键为元素值，值为优先级
出队多余的元素
将优先队列中的元素出队记录到数组中 `return`

```
dic = new();
pq = new();
for i = 0; i < nums.Length; i++
	dic.TryGetValue(nums[i], out int count)
	dic[nums[i]] = count + 1
foreach var item in dic
	pq.Enqueue(item.Key. item.Value)
	if (pq.Count > k)
		pq.Dequeue()
result = new int[k]
index = 0
while pq.Count > 0
    result[index++] = pq.Dequeue()
return result
```

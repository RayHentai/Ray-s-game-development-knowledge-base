## Span\<char>

**`Span<char>`**

一种高性能的内存切片，不需要额外分配内存，直接在原数组上操作，比普通char数组省一次内存分配。

```csharp
Span<char> span = s.ToCharArray().AsSpan();
```

## .. 范围语法

C# 8.0以上的切片语法，`i..(i+k)` 表示从i到i+k的范围，`..`的范围等同于\[i , j) 左闭又开，写法更简洁。
如果是 `i..` 则代表从i开始一直到最后一个数（包含）

**`span[...].Reverse()`**

直接对切片调用Reverse，省去了手写对撞指针交换的代码。

```csharp
span[i + k < span.Length ? i..(i + k) : i..]
// 等价于
// 如果i+k没越界，取i到i+k这段
// 否则取i到末尾这段
```

思路和你的完全一样，只是用了更现代的C#语法糖。空间复杂度上Span不额外分配内存，比你的O(n)更优，是O(1)。

在范围语法中 `^n` 表示倒数第n位
`[1..^1]`  表示从索引 `1` 到索引 `Length - 2`

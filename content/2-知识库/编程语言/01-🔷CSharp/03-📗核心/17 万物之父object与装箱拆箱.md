## 核心理解

> `object` 是所有类型的基类，它是一个类（引用类型）。
 
---

## 装箱拆箱

**用object存值类型（装箱）**
- 把值类型用引用类型存储
- 栈内存会迁移到堆内存中

**把object存储的值类型转为值对象（拆箱）**
- 把引用类型存储的值类型取出来放入值对象中    
- 堆内存会迁移到栈内存中

```csharp
// 装箱：用 object 存值类型
// 把值类型用引用类型存储，栈内存会迁移到堆内存中
object obj = 1; // 装箱：int → object

// 拆箱：把 object 存储的值类型取出来放入值对象
// 堆内存会迁移到栈内存中
int i = (int)obj; // 拆箱：object → int

// 引用类型用 as
object obj2 = "1234";
string str = obj2 as string;

//实操 
```

**优缺点：**
- 优点：不确定类型时可以用 object 存任何类型，方便参数的存储和传递
- 缺点：存在内存迁移（栈↔堆），增加性能消耗

---

## 装拆箱对性能的影响

装箱 = 堆上新开空间 + 把值拷贝进去 + 栈上的引用(o)存这个堆对象地址。
拆箱 = 把堆对象里的值再拷贝回栈上的值类型变量。

**两次都是拷贝。**

装箱要**在堆上分配内存**(堆分配比栈慢),还要拷贝数据;
更狠的是——这个堆对象后面还得 **GC 来回收**(接上你刚学的:堆对象靠 GC、GC 有开销)。

所以装箱的真正代价是**堆分配 + GC 压力**,不是"转换"这个字面动作。

危害场景:如果在循环里、或 Update 里频繁装箱,就会疯狂产生小的堆垃圾 → GC 频繁触发 → 卡顿。

装箱就是一种**隐蔽的**堆分配(你没写 `new`,但 `object o = i` 背地里 new 了)。这是它比普通 new 更坑的地方:看不见。

---

## 什么时候用

> 适用场景，帮助建立使用直觉

- 可以利用里氏替换原则，用 object 容器装所有对象。
- 可以用来表示不确定类型，作为函数参数类型。

## 练习

> 1. 请口头描述什么是装箱拆箱


装箱：把值类型用引用类型（object）存储，值从栈内存迁移到堆内存
拆箱：把 object 中存储的值类型取出来，从堆内存迁移回栈内存


> 2. 请用代码描述装箱拆箱

```csharp
// 装箱
object obj = 1;
object obj2 = "1234";

// 拆箱
int i = (int)obj; // 值类型用括号强转拆箱
string str = obj2 as string; // 引用类型用 as 拆箱
```

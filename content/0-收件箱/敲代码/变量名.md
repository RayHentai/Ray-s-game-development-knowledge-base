C# / Unity 命名规范(你以后一直用这套):

| 成员类型               | 规范                      | 例子                     |
| ------------------ | ----------------------- | ---------------------- |
| **public 字段 / 属性** | 大驼峰 PascalCase          | `Instance`             |
| **private 字段**     | 小驼峰 camelCase,常加 `_` 前缀 | `_updateEvent`         |
| **方法**             | 大驼峰 PascalCase,**动词开头** | `AddUpdateListener`    |
| **event**          | 大驼峰,常用**名词**或 `On`+事件名  | `UpdateEvent`          |
| **参数 / 局部变量**      | 小驼峰 camelCase           | `updateFun`            |
| **类 / 接口**         | 大驼峰,接口加 `I`             | `MonoMgr` / `IManager` |

游戏开发高频命名词典(按你会反复用到的):

|中文意图|英文|说明|
|---|---|---|
|添加 / 加|`Add`|加监听、加元素|
|移除 / 删|`Remove`|跟 Add 成对|
|帧更新|`Update`|就是生命周期那个词|
|物理帧更新|`FixedUpdate`||
|延迟帧更新|`LateUpdate`||
|监听者 / 监听方法|`Listener`|加在后面,如 `UpdateListener`|
|开启|`Start`|开协程|
|停止 / 关闭|`Stop`|停协程,跟 Start 成对|
|协程|`Coroutine` / `Cor`|全称或缩写|
|事件|`Event`||
|管理器|`Manager` / `Mgr`|Mgr 是常见缩写|
|单例实例|`Instance`||
|获取|`Get`|取值|
|设置|`Set`|存值|
|创建|`Create`||
|初始化|`Init`(Initialize)||
|清空|`Clear`||
|池 / 对象池|`Pool`|下个模块要用|

**构词方式**:动词 + 名词,拼起来。"加帧更新监听者" = `Add`(加) + `Update`(帧更新) + `Listener`(监听者) = **`AddUpdateListener`**。你看,你中文拆出来的四个字,一个词对一个词拼上去就是标准名。

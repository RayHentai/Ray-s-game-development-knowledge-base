## ContainsKey的优化

```csharp
for (int i = 0; i < nums.Length; i++){
	if (dic.ContainsKey(nums[i]))
		++dic[nums[i]];
	else
		dic.Add(nums[i], 1);
```

```csharp
for (int i = 0; i < nums.Length; i++)
{
	dic.TryGetValue(nums[i], out int count);
	dic[nums[i]] = count + 1; //没有对应键会自动新建键
}
```

## 元组结构赋值 替代 temp赋值

只是写法上更优，性能完全一样

```csharp
TreeNode temp = node.left;
node.left = node.right;
node.right = temp;
```

```csharp
(node.left, node.right) = (node.right, node.left);
```

## 2的幂运算


`Math.Pow(底数, 指数)` 返回 `double`，需要转成 `int`。

```
(int)Math.Pow(2, 3)
```

或者用位移 `1 << 指数` 更简洁，等同于 `2^指数`。

```
1 << 3
```

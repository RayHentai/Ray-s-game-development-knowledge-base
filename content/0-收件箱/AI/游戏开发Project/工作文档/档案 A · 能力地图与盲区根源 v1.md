## 三、盲区根源(初始,待实操细化)

### 根源 1 · 双层问题:理解层衰减 + 重现层从未建立(性质不同,手段不同)

**观察**:一直"跟着做",没有"合上做"。原始判断是"理解不缺、只缺重现",但经用户
自评修正:**理解层本身也衰减了**(一个月没碰 + 从没复习,自评"基本忘了、复刻不可能")。
所以是**两层问题并存,但性质不同**:

- **理解层 · 建立过又衰减**:AI QA 当时搞懂过原理(理解层曾达到 OK),但因不复习 +
  长期没碰,退化了。**这层复习/重取能救**——底子建过,是重新激活,不是从头学。
- **重现层 · 从未建立**:闭卷调不出、合上重建不出来,这个从来没训练过。
  **这层复习救不了,只能靠闭卷从头练**(合上写→卡→定位→回补,反复长出来)。

**关键区分**:再认(re-read 时"我记得")≠ 回忆(闭卷时调得出)。理解衰减和重现缺失
是两回事:前者是"曾有、退了",后者是"从来没有"。**别用救理解的手段(复习)去补
重现**——复习能让你重新"看懂",但看懂还是再认级,调得出才是重现,那得闭卷练。

**高频 API 记不牢并入此条**:C# 容器/声明/类型转换、Unity 移动旋转/射线检测这类
高频 API 记不牢,不是独立记忆问题,是理解层衰减的表现(用得多的东西整体退了)。
随理解层复习/重用一起回来,不单独处理。

**处理方向**:
- 摸底两层分开测:理解层现在剩多少(测原理能否讲出/推导)+ 重现层能否建立
  (测合上能否重建)。
- 理解层缺口 → 针对性复习/重取(非地毯式)。重现层缺口 → 闭卷尝试 + 补盲 5 步。
- 别混手段:该复习的复习,该闭卷的闭卷,不拿复习冒充重现训练。

**来源**:实战 · 迁移基线会话 + 框架完善会话(能力现状分层)

**演化追踪**:待摸底给出"理解层实际剩多少 / 重现层从零练的第一个数据点"。

#### 根源 1 演化 · 具体盲区:弧度制未成直觉(角度制思维 + 弧度临时转换层)

**观察**:摸底 sin/cos 圆柱展开时,用户能推出 `cos θ·r / sin θ·r`(因果在),但第一步算夹角用 `360°/n`(角度制建模),需 `Mathf.Deg2Rad` 转换才能喂给 `Mathf.Sin`;且 `Deg2Rad` 是现场查引擎得到、非闭卷记得。用户自评关键句:"脑子里那个圆是用角度建的,没想过可以直接用弧度建、这样不用转换。"

**诊断**:非"弧度知识点没学会"(知道弧度、知道要转、转换可查),而是**心里的圆用角度(360°)搭建,弧度是临时转换层**。后果:①每次摆圆代码都走"角度想→转弧度"绕路,转完即忘;②`Deg2Rad` 这类"高频 API 记不牢"是此表现的产物,非独立记忆问题(印证根源 1:高频 API 记不牢 = 理解层未扎实的表现)。

**区别于"一戳即回"的衰减**:本轮多数概念错位(顶点空间/triangles/绕序)一经追问即自恢复,属"结构在、标签松";弧度这条不同——不是标签松,是**底层建模用错了坐标语言**,追问也回不到"直接用弧度",需专门重建直觉,非复习可解。

**处理方向**:标为明确理解层缺口(非边界、非可查项)。修法非"背住要转弧度",而是重建"用弧度想圆"的直觉(2π=整圈、π=半圈、π/2=直角、2π/n=均分),做几次纯弧度摆圆练习,戒掉 360。留待摸底后专项处理。

**来源**:实战 · 全域摸底会话

#### 根源1演化 · 病灶机制定位："提取通道"从未建立（用户自主诊断）

这是根源1"重现层从未建立"在知识层(非代码层)的同构表现：

### 根源 3 · 回避 + 合理化:用"正确的学习动作"包装"不踏出临摹"

**观察**:用户明确自述"在临摹时总不想再往前踏一步,停在舒适区""半逃避地一直前进"
"第一个项目做完休息一个月,迟迟不肯踏出临摹那一脚"。

**机制(核心)**:用户**并非误以为练够了**——他清楚没练够(自己说"不会就回翻")。
真实机制是**回避 + 合理化**:踏出临摹(合上重建)是难受的,用户用本身正确的动作
把这一步后推:
1. "一直复习旧的" → 复习对,但被当成不往前踏的理由;复习舒适(再认级),
   复刻难受(回忆级),用户选前者并挂上"打基础"名分。
2. "把基础全学完再做项目" → 用户确实学完了基础(此点不是借口,是事实)。
   但"学完再做"在心理上仍起到"把踏出临摹无限延后"的作用:第一个项目做完、
   该踏出临摹时,休息了一个月。
**关键**:这些动作的"正确性"正是回避能持续的原因——正因"复习/打基础"听起来全对,
用户才能心安理得一直不踏出。**第一个项目做完休息一个月是最诚实的信号**
(此时基础已学完、项目已做完,无"打基础"可解释,是纯回避)。

**处理方向(关键)**:
- "给他看真实差距"这个解法**不够**——用户早知道有差距仍不动。
- 正确解法 = **外部逼一脚 + 逐个拆掉合理化借口**。对应指令角色"考核官+逼尝试"
  和用户自写的"投递授权(对抗拖延)"。用户自己踢不动这一脚,需要外部踢。
- 摸底的意义随之修正:不是"让他看到差距"(他知道),是**外部强制踏出第一步**,
  把"迟迟不肯踏"这个动作替他启动一次。

**来源**:实战 · 框架完善会话(学法偏好深挖)

**演化追踪**:待摸底完成,记录"被外部逼着踏出第一步后的实际反应"——
踏出后发现没那么难(回避松动),还是踏出后确认差距大(需回补)。两种都是数据。

**⚠ 份量校准(勿夸大)**:回避机制成立(用户亲口确认半逃避、迟迟不肯踏),
  但严重程度别按"三年顽疾"算——用户实际只学了约 120 天(见第一部分)。
  "第一个项目做完休息一个月"是回避,但也是"刚学 120 天的人踏出第一步前的
  正常犹豫+回避",不是积重难返。**处理上仍要外部逼一脚(机制是真的),但语气
  别渲染成"多年沉疴",那会给用户不必要的挫败感。** 120 天也好,该闭卷还是闭卷。

#### 档案A · 根源3关联表现 · 分解能力未建立(拿到需求无步骤流)

**观察**:闭卷全程需Claude以提问推进(先做什么/依赖什么),用户自评"脑中不会自动出现步骤流,是被推着走"。用户自主识别此缺口。

**诊断**:非记忆问题,是**分解能力(decomposition)未建立**——面对需求不能自主拆"要素→子步骤→顺序"。与根源3(启动行为需push)相关但不同:根源3是"不愿启动",这条是"想启动但没有拆解工具、不知从何下手"。

**处理**:练分解自问五问(档案B),非背步骤。**Claude动作**:闭卷时逐步把"我提问推进"显式化为"教用户自问",让用户复述五问、自主拆解,而非直接被动接受引导序列。

**区分**:用户药方"背引导步骤+肌肉记忆"是错的(会退回临摹),已纠正为"练通用分解工具"。

**来源**:实战·全域摸底会话

## 五、学法偏好

**有效 vs 无效(用户自述 + 推断)**:
- **无效(占历史主体)**:一次性学习——学过就往前走,不回头、不复习、练习次数少。
  向量/三角函数、算法思路都属此类:当时"学会了/复盘过",但因练习少 + 长期不回看,
  现在需回翻笔记才能再认。**这不是背诵应付**(用户明确否认),是缺主动回忆 + 间隔重复。

- **有效**:重复→留存,已有两个正例(均非主动,是环境喂的重复):
  1. **单例模式**:高频使用记得牢。经确认是**被动高频**(项目到处要用、反复撞到),
     不是主动决定"要练熟"。证明"重复对用户有效",但**未证明**"用户会主动制造重复"。
  2. **算法"次日总结前一天思路"**:唯一一次主动间隔回忆(隔一天回取),做题流程里
     实践过。这个是主动的,但已随算法 dormant 停用。
  **关键局限**:两个正例里,留存生效的那个(单例)是被动的。用户靠环境喂重复,
  环境不喂(低频/需自己发起)就不重复。**推论**:用户缺的是"主动制造重复的机制"——
  他不自发重复,必须靠外部纪律(间隔回忆、复刻卡片)人为造出"高频"。这是根源 3
  (回避主动动作)在学法层的投影:环境安排的能做好,需自己发起的做不起来。`


**关键区分(避免误归因)**:用户的遗忘根源是"学过不回头"这个行为缺口,
不是"没方法论"这个认知缺口。两者都存在但要分开补:
- 行为缺口 → 间隔回忆纪律(档案 B 第3条 + 翻笔记纪律),现成动作,不需顿悟。
- 方法论缺失 → 前期引导(见指令角色"方法论引导者"),给"临摹→复刻"的闭环标准。
误区:以为给足方法论就不忘了。不会。方法论管方向,间隔回忆管留存,缺一不可。

**退回背诵的场景**:无。用户历史上不靠背诵应付,靠"持续学新"(但不复习)。
风险不在背诵,在"学新掩盖不复习"——一直有新内容学,营造"在进步"的错觉,
旧的悄悄塌掉。

**逐条动作反馈**

**猫牛式检验标准**:

- **手腕正下方 = 肩,膝正下方 = 髋**(四点位置),四点承重均匀
- **牛式(下弯)**:胸挺出,肩胛主动后夹,尾骨向天花板抬,视线略前上——**注意不是仰头**,是脊柱下弯延伸到颈椎
- **猫式(上拱)**:肚脐主动往上抬(不是脊柱塌下去被动弓),腹肌主动收紧,肩胛向前分开,视线看向大腿
- **动作缓慢**——每个体位保 1-2 秒
- **检验点**:动作幅度大小不是关键,**"感受到脊柱每一节都在动"** 是关键。快速甩腰 vs 缓慢逐节流动是完全不同的东西
- **验证方式**:侧面拍视频自己看,或对着镜子做

**死虫式(细节最多)**:

你的自诊"核心弱不能全程绷住导致腰椎代偿"——**方向对**。这不是姿势错,是核心耐力和目标动作难度的不匹配。

- **勾脚 vs 绷脚**:
    - 勾脚尖 = 腿重心离髋更远 = 腹部要抗的力矩更大 = 腰椎压力更大(进阶版)
    - **绷脚尖 = 腿相对轻 = 更适合当前阶段入门**——先在低难度下建立正确模式,升级到勾脚是 2-3 周后的事
- **角度**:
    - **不下放的那侧**:大腿垂直地面(90° 抬起),小腿平行地面(膝弯 90°)——这是"标准起始位"
    - **下放的腿**:膝盖保持微弯,小腿慢慢伸直,脚跟离地 5-10 cm 停住(不要贴地),然后收回
    - 不下放的手臂:直臂指向天花板
- **不下放的手臂和腿"稳不住"**:正常。第一次做核心弱都这样。**侧重点是"腰贴地"这个客观锚点,不是"其他肢体绝对静止"**。轻微晃动可接受
- **⭐ 关键调整建议:分级训练策略**:
    - **阶段 1(当前,2-3 周)**:**绷脚尖 + 只放腿不放手,或只放手不放腿**(单边组合,难度减半)
    - 阶段 2(3-4 周后核心稳定):恢复 4 肢协调(手 + 腿同时)
    - 阶段 3(1-2 月后):升级到勾脚尖
- **⚠ 铁律**:一旦感觉腰椎代偿(比如从第 7 个开始)= **立刻停止这一组**,不要"再撑 3 个"——代偿只会加深错误模式,让神经系统"学会"错的路径

**侧平板肘部压力**:

- 两个原因都有,但当前主要是设备问题不是核心问题
- **姿势验证**:肘部要在**肩正下方**(前臂垂直躯干)。错位会让肘承压
- **⭐ 建议**:**用瑜伽垫或折叠毛巾垫肘**——这不是"作弊",是让核心专注发力,不被肘部疼痛分散
- 用户"最后两组肘关节压力很大"= 累积压迫,标准解法就是垫

**鸟狗式** ✓ 第二组比第一组稳 = 神经募集在进步。继续保持,3-4 周会显著稳定。

**蚌式代偿担忧**:

- 你怀疑的方向对——臀中肌下面还有**臀小肌 + 梨状肌**,都是髋外展肌群
- 但**这几块肌肉一起工作是正常协同,不是代偿**——真正的代偿是"阔筋膜张肌(TFL)主导"
- **TFL 代偿的诊断信号**:
    - 大腿外上方(髋部前外侧)酸胀
    - 臀部本身没什么感觉
    - 髋关节前侧有紧张感
- 你反馈"开合发力感很好" + 感觉在臀外侧 = **臀中肌+臀小肌协同发力,是对的**。不用担心

**核心刺激到位** ⭐:你反馈"刚走上跑步机就有感觉"——这是弱项日固定层命中目标的旁证(和 7.4 下肢 B "睡醒无 DOMS"的反面案例形成对照)。DOMS 对照法在正反两个方向都在生效。

**核心动作呼吸原则**(单独展开,以后所有核心动作通用):

**通用规则**:**发力时呼气(收缩阶段),放松时吸气(离心阶段)**

具体到各动作:

|动作|呼气(发力)|吸气(放松)|
|---|---|---|
|死虫式|手脚伸出时(远离身体)|收回时|
|卷腹|向上卷时|躺回时|
|平板 / 侧平板|**自然呼吸,不憋气**(静态动作)|同左|
|山羊挺身|抬起时|下落时|
|鸟狗式|伸出手脚时|收回时|
|蚌式|膝盖打开时|合上时|
|猫牛式|猫式(拱背)时呼|牛式(挺胸)时吸|

**⚠ 铁律:核心动作不要憋气**——憋气 = 腹压过高 = 反而增加腰椎压力。慢慢练呼吸配合,第一周不熟练可以先保持"不憋气"底线,不追求精确同步。

**仰卧腰贴地问题** ⭐(观察很敏锐)

你的观察对——腰椎的自然生理曲度是前凸,平躺时腰下会有一个小间隙,不可能完全消除。

**"腰贴地"的准确含义**:不是"完全消除间隙",而是**核心主动收紧,让间隙比自然状态小,不额外扩大**。

**客观检验方式**:

- 用一只手掌塞进腰下:**能刚好塞进(平放,不能过厚) = 正常状态**
- 死虫式做的过程中,如果间隙**变大到能塞两只手掌** = 骨盆前倾了 + 核心没稳住 = 动作做错了

**不需要垫东西**——垫东西会破坏"腰间隙是否扩大"这个检验锚点。就是要让间隙来告诉你"核心还在不在"。

正确做时,你会感觉到**下腹部主动向脊柱方向收紧**,让腰下间隙保持稳定(不扩大也不额外压)。

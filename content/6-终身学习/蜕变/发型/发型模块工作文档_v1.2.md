## 第一部分:基础事实

### 1.1 头发现状(2026.6.27)

- **长度**:发尾到下颌线附近,中长发
- **发量**:**非常多**(普通男生的 1.5-2 倍),是核心物理约束
- **发质**:天然直发,但内层有上次烫发的残留卷度(正在自然褪去)
- **发际线**:太阳穴两侧轻微 M 型,中分自然垂下能盖住,全后梳会暴露
- **几个月没修剪**,发尾有参差但不严重

### 1.2 脸型与五官

- **脸型**:长方形 / 偏长椭圆(脸长 > 脸宽,下颌线条清晰但不外扩)
- **骨相**:下颌清晰、鼻梁有形、五官立体,**能撑日系长发**
- **变化趋势**:5 年照片对比,从"少年圆润"变成"青年清瘦",**下颌线和骨骼感在变好**
- **当前减分项**(非骨相):
  - 皮肤出油明显
  - 胡子未刮也未修,卡在"懒"和"留"之间
  - 长期居家导致身体语言偏松散

### 1.3 工具盘点

**已有:**
- 吹风机(品牌/功率不详,需补一字风嘴)
- 甲板(直发夹板)
- 啫喱
- 发泥(hair clay)

**待补(优先级):**
- ⭐ 吹风机一字风嘴(5-15 元)→ 必补
- 吹风机支架(20-40 元)→ 强烈建议,解放双手
- 防晒霜(40-80 元)→ 求职期出门必备

## 第二部分:风格方向

### 2.1 已确定的方向

**日系直发垂坠,90 年代男星气质**

**主参考图谱**:
- 横滨流星(中长发期):清冷、文艺、垂坠
- 竹野内丰(90 年代):自然不羁,带骨感
- 金城武(早期长发):直发垂坠,简洁

**核心结构要素**:
- 中分自然垂下
- 前发盖部分额头(露出一小块中间区域)
- 长度到下颌或锁骨之间
- 两侧自然垂落、不外扩
- 发尾向下或微内,**不外翻**
- 头顶贴合,不堆体积
- 整体接近"一刀齐",不要 hush cut 的内短外长

### 2.1.5 关于横滨流星的深层共鸣(重要,延伸到其他模块)

用户对横滨流星明显有更强共鸣,挑了三张参考图都是他。
分析他作为"参考人"代表的整套气质:

- 五官清秀但不精致到偶像化
- 气质偏冷、偏沉静
- 衣着偏极简(全黑、白衬衫)
- 长发但不张扬

**和韩式偶像的车银优形成对比**:车银优是"明亮 / 阳光 / 偶像感",
用户对此明显没共鸣。

**含义**:用户倾向的不只是"日系发型",而是**整套"清冷文艺"的气质方向**。

**对其他模块的指导意义**:
- **眼镜模块**:框型应支撑"清冷文艺"而非"潮男"或"明亮阳光"
- **穿搭模块**:极简、冷色、利落剪裁优先于花哨、暖色、装饰繁多
- **皮肤模块**:皮肤越干净,"清冷"质感越能立住
- **整体气质**:松弛而非刻意,克制而非张扬

### 2.2 已排除的方向

| 方向               | 排除理由                   |
| ---------------- | ---------------------- |
| **韩式 hush cut**  | 不符合气质偏好,过于精致/偶像感       |
| **K-pop mullet** | 风格太强,求职期不合适            |
| **半扎**           | 同上                     |
| **任何染色**         | 预算 + 优先级双低             |
| **烫发(现阶段)**      | 5 年发型史证明对你是减分操作,等有钱再重评 |
| **大幅剪短**         | 除非长发路线最终验证失败,否则不动      |
| **全后梳油头**        | 暴露发际线 + 拉长脸 + 暴露皮肤问题   |

### 2.3 关于"驾驭"的认知

**这个发型吃什么**:
- 骨相清晰度 → 你够
- 皮肤状态 → 你目前不够,需要改善
- 眼神和姿态 → 你能做到(画画那张证明了),但日常需维持
- 整体松弛感 → 这是日系核心,刻意=失败

**这个发型不太吃什么**:
- 五官精致度(竹野内丰粗犷型也能撑)
- 双眼皮/鼻型等具体指标
- 脸的大小

## 第四部分:当前卡点诊断

### 4.1 核心问题

**发量过多 + 内层未打薄**

物理后果:
- 自然干 → 头发向外炸开,像钢盔
- 全后梳 → 头顶堆体积,暴露发际线
- 烫发 → 体积爆炸(历史已验证)

### 4.2 当前进度自评(2026.6.27 凌晨)

| 维度 | 状态 |
|------|------|
| **方向确定度** | ✅ 已锁定(日系直发垂坠) |
| **目标图清晰度** | ✅ 已锁定(Image 3 横滨流星等) |
| **当前发型框架** | ✅ 接近目标(侧面已对) |
| **发量打薄** | ❌ 未做(下一步关键动作) |
| **打理技能** | ⚠️ 在学习中(两次失败,卡在"吹不干") |
| **理发师选择** | ⚠️ 暂用 2024.12 那位试一次 |
| **工具完备度** | ⚠️ 差一字风嘴和支架 |

### 4.3 侧面 vs 正面差距分析

**侧面已经接近目标**(Image 3 横滨流星):
- 长度对
- 方向对
- 垂坠感对
- 发尾基本向下

**正面还有差距**:
- 体积过大(两侧蓬)
- 整体厚重感强

**结论**:**方向没错,缺一刀内层打薄**。

### 4.4 AI 生成图实验记录(方法论)

用户在推进过程中用 ChatGPT 生成了两次目标参考图,经验如下:

**第一次生成**:
- 给了原图 + 描述,生成图 7 分像
- 问题:AI 偷偷给头发打薄了 ~30%、把头发理顺了、皮肤优化了
- **本质**:AI 给的是"剪 + 打理后的天花板状态",不是真实可达成

**第二次生成**(改进提示词,要求保留真实状态):
- 失败:打薄过度、前发变形、发尾出现 hush cut 羽毛尖
- **原因**:AI 朝着另一个方向跑偏,理解错了"打薄"的程度

**结论与方法论**:

1. **AI 图能给方向参考,但永远高于真实可达成状态**
2. **AI 图生成有不稳定性,3-5 次未必都满意**
3. **AI 图可作为理发师沟通辅助工具**(和真人参考图一起带去)
4. **不要把 AI 图当成"应该达到"的标准**,把它当成"努力的方向"
5. **真人预实验 >> AI 模拟**,真实头发是确定的事实

  关键点是要求"不要美化皮肤""不要修整胡子""不要改变骨相",

| 陷阱 | 应对 |

**Action 2:打理技能练习**

**关键修正**(基于今晚两次失败):

1. **吹风时间**:实际需要 **12-15 分钟**(不是 3-5 分钟)
   - 用计时器,别相信"感觉差不多了"
   - 抓头发感觉"轻盈蓬松"才是 90% 干,"沉重贴头"就是还湿
2. **发尾方向**:**往脸/往下勾**(像塞耳后的开头动作),**不是往耳朵上方**
3. **分大区,不一撮一撮**:
   - 左前(太阳穴到耳朵前):精修
   - 右前(同上):精修
   - 后面三个区:粗放,5 分钟解决
4. **甲板用法**:
   - 温度 150-160°C
   - 只夹发尾,不夹头顶
   - 左前:逆时针 1/4 圈往下拉
   - 右前:顺时针 1/4 圈往下拉

**完整流程**(下次洗头按此执行):

```
1. 洗头(温水,洗头皮不洗头发)
2. 毛巾反复压干 5 分钟(减少吹的负担)
3. 吹头顶定根 3 分钟
4. 吹两侧各 2-3 分钟(手按头发往下顺)
5. 吹发尾 3 分钟(手勾住往脸方向)
6. 总吹风时间 ≥ 12 分钟
7. 冷却 2 分钟
8. 甲板顺发尾 3-5 分钟
9. 发泥抓两侧束感(可选)
10. 拍照(后置主摄 + 自然光 + 三个角度)
```

**Action 4:预实验拍照规范(评判进度的统一标准)**

每次打理实验后,**用统一标准拍照**,这样跨实验对比才有意义。

**拍摄要求**:
- **后置主摄**(不用前置:前置镜像、有美颜、广角畸变)
- **不用 0.6x 超广角**(会变形)
- **自然光优先**(白天靠窗;不要浴室暖灯)
- **距离镜子 50-80cm**
- **手机举到脸前**(不俯不仰)
- **关闭闪光灯**

**三个固定角度**:
1. **正脸**:看头发整体轮廓、中分位置、两侧是否对称
2. **微侧 45 度**:看头顶高度、前发盖额角度、发尾方向(最接近别人看你的真实视角)
3. **完整侧脸 90 度**:看发尾长度、后脑勺到颈部轮廓、两侧发量分布
   (最能判断发尾向下/向外的差别)

**判断时机**:
- 打理完**维持 1-2 小时后再拍**(刚弄完和稳定后状态不同)
- 不要立刻评判好坏

**评判基准的递进**:
- 第 1-3 次实验:跟"自然干炸开"那张比,进步多少
- 中期:跟"上次实验"比
- 长期:跟"Image 3 横滨流星"比(不要一开始就跟它比,会挫败)

**Action 5:失败实验经验记录(避免重复踩坑)**

**2026.6.27 凌晨的两次失败**:

**失败原因 1:吹风时间严重不足**
- 用户主观:"我吹了很长时间"
- 实际时长:可能 3-5 分钟
- 正确时长:**12-15 分钟起步**
- **教训**:发量多的人,吹干长发的实际时长接近女生水平,不是 3 分钟搞定

**失败原因 2:吹风机烫手 + 凌晨噪音 + 自己吹自己反人体工学**
- 客观约束:手臂角度不顺、单手不够用、看不到后脑勺
- 不是"毅力不够",是工具和场景问题
- **解决方案**:
  - 一字风嘴拉远距离能减少烫手
  - 吹风机支架解放双手
  - 噪音问题:晚上压干 + 短吹 + 早晨补吹
  - 后脑勺别折腾(自己看不到的地方,别人也基本看不到)

**失败原因 3:对湿发用甲板**
- 物理事实:湿发遇高温会损伤;水分还在,定型会回弹
- **正确流程**:吹到 90% 干 → 冷却 1-2 分钟 → 才能上甲板

**失败原因 4:动作方向错误**
- 错:发尾"往耳朵上方"移动 → 头发记住"向上"方向 → 外翻
- 对:发尾"往脸 / 往下勾"(像塞耳后的开头) → 头发向下垂

**失败原因 5:一撮一撮操作太累**
- 错:每一小撮头发都精修
- 对:分大区(左前、右前精修;后面三区粗放)

**这些失败的方法论价值**:
- 失败本身是数据,记录下来比"没失败过"更有用
- 下次实验前,把这些原因当 checklist 过一遍

   - 共同点:**短发 + 自然 + 不刻意造型 + 处于专注/放松状态**
   - 其中"画画那张"被多次引用为基准——**专注状态下颜值发挥最高**
2. **5 年里"最不好看的状态"**:几乎全部是烫发
3. **2021 年是 5 年里状态的最高峰**:短发期密集,五官还没完全长开但状态最对
4. **2022 年开始陷入"烫发 → 长 → 烫发 → 长"循环**:一直延续到现在
   - 每次烫发的间隔在**缩短**
   - 含义:你在不断追求"理想状态",每次都失望,然后更快地再试一次

### 7.2 五官变化趋势

- 从"少年圆润"(2020-2021)变成"青年清瘦"(2024-2026)
- **下颌线在变清晰、骨骼感更明显**
- 含义:18-20 岁不适合的某些发型,24 岁可能适合;
  但**烫发是例外**,5 年里没有任何一次烫发让你状态变好,这条线建议彻底放弃。

### 7.3 配饰使用的观察

- 项链、耳钉、手链在 5 年里出现频率较高
- 含义:你对配饰有**潜在的审美意识和接受度**
- **对穿搭模块的输入**:配饰可作为穿搭的重要组成部分,不需要被排除

### 7.4 重要含义(指导未来决策)

- **短发是经过验证的安全区**,如果长发路线最终验证失败,有退路
- **烫发是经过验证的雷区**,这条线在 v2 之前不动
- **专注/放松状态本身就是颜值的一部分**,不只是发型在起作用
- **24 岁的脸 ≠ 18 岁的脸**,过去的失败发型不一定永远失败(烫发除外)

## 第八部分:用户提问记录

> 此部分记录用户在推进过程中提出的关键问题。
> 这些问题暴露了用户思考的角度和卡点,以后再次推进时可复用。
> 按主题归类,时间顺序保留。

### 8.1 预算与决策类

- **"用 3 个月,4500 元生活费,你觉得形象投入多少比较合理?"**
  - 触发了整体预算拆解
  - 暴露的思考角度:不接受笼统建议,要求基于真实约束算账
- **"这样修剪,和我后面有条件了可能会烫头冲不冲突?"**
  - 暴露的思考角度:考虑当前决策的长期影响,不想做"白干"的事
- **"我能不能随便找一家理发店把头发在保持长度的基础上稍微修剪一下?"**
  - 暴露的思考角度:在"完美方案"和"可执行方案"之间找平衡

### 8.2 自我认知类

- **"我不是很喜欢韩式风格,更喜欢日系一点的"**
  - 直接的偏好声明,后来被发现"自以为的日系"其实是韩式
  - 暴露的思考角度:有审美直觉但词汇不精确,需要被校准
- **"我还不知道我自己是什么脸型,适合什么发型"**
  - 暴露的思考角度:愿意承认知识盲区,要求被教
- **"这种发型吃不吃颜值?"**
  - 暴露的思考角度:对"是否能驾驭"有真实焦虑,要直接答案
- **"建模不行,驾驭不了这个发型,换一个吧"**
  - 在受挫时倾向放弃当前方向
  - **注意**:这是个需要警惕的模式,Claude 应该判断是真不适合还是临时受挫

### 8.3 视觉判断类

- **"我现在的头发是不是已经差不多干了,定型,其实说实话已经看到一些效果了。
  比自然干会好很多。为什么正面看起来还是体积太大。是不是受上一次烫发的影响很大,
  以及受我几个月没修剪头发的影响"**
  - 这是今天最高质量的提问之一
  - 暴露的思考角度:自己观察 + 自己假设 + 求证,而不是只要答案
- **"用前置还是用后置和人眼看到的更像"**
  - 暴露的思考角度:质疑工具本身的偏差,不是只用工具

### 8.4 操作细节类

- **"把头发往下扯,然后吹吗,还是往脸上压?"**
- **"吹风机是直接吹还是用一字的风头吹?"**
- **"怎么卷?"**
- **"假设我现在用夹板夹着左边刘海的发尾,是顺时针旋转还是逆时针旋转?"**
- **"整个头发的发尾吗,假设我现在用夹板夹着左边刘海的发尾..."**
  - 暴露的思考角度:**要求精确到动作级别的指令**,模糊指令对你无效
  - 这是个重要信号:以后给你流程时,默认要拆到"具体手势 + 具体方向"

### 8.5 沟通方式类(对 Claude 的反馈)

- **"你以后不要让我知难而退,除非我叫你给我提建议"**
  - 已纳入对话原则
- **"不需要这种客套迎合,你通过对话展示出'人味'就行了"**
  - 已纳入对话原则
- **"你忘了吗?" / "我每次向你提的问题你怎么没总结进去"**
  - 暴露的思考角度:对"被认真对待"和"被完整记录"有要求
  - 对 Claude 的隐含期待:记忆要长、跟踪要细

### 8.6 提示词与工具使用类

- **"你帮我生成一个提示词,我让他再生成一张图片,更精准一些"**
  - 主动使用 AI 工具,需要 Claude 配合输出工具指令
- **"我想用这张再试试,帮我生成一个提示词"**
  - 迭代式使用 AI,不是一次性

### 8.7 总结与归档类

- **"那,关于发型到目前为止的总结工作呢"**
  - 主动要求阶段性归档
  - 暴露的思考角度:需要文档化,不依赖对话记忆
- **"详细版本。这个文档要一直迭代的"**
  - 明确要求长期维护机制

### 8.8 元对话类(用户主动塑造协作方式)

> 这一类记录的不是"问问题",而是用户**主动定义我们怎么工作**的发言。
> 这是协作关系本身的重要数据,以后不需要每次重新教 Claude。

- **"你以后不要让我知难而退,除非我叫你给我提建议"**
  - 含义:不要预先设置"你做不到"的暗示
  - 已纳入对话原则
- **"不需要这种客套迎合,你通过对话展示出'人味'就行了"**
  - 含义:拒绝模板化的礼貌客套,"人味"要从内容里出
  - 已纳入对话原则
- **"你忘了吗?"**
  - 含义:对"上下文丢失"敏感
  - 隐含期待:Claude 应该跟踪足够细
- **"记得什么,你是不是不想继续回我了"**
  - 出现在 Claude 提供选项让用户选时
  - 含义:不接受"被推开",但也不希望被无条件迎合
- **"我每次向你提的问题你怎么没总结进去"**(就是导向本节存在的发言)
  - 含义:提问本身也是有价值的数据,需要被记录
  - 直接导致了**第八部分的诞生**
- **"加吧,加完再检查一下"**(就是导向 v1.2 的发言)
  - 含义:Claude 应该具备自检意识,不要等用户指出疏漏
- **"每次迭代也生成一份详细点的笔记文档,我要放到 obsidian 中去"**
  - 含义:工作文档(成品)和迭代笔记(过程)应该分开维护
  - 直接导致了**配套迭代笔记机制的诞生**

**这一类的含义**(给 Claude 的隐式指令):
1. 你需要被认真对待 → Claude 不要客套
2. 你的每条思考都有价值 → 完整记录
3. 协作方式的塑造也是工作 → 把这些发言本身存档
4. 自检意识要主动 → 不要等用户指出疏漏

## 附录 A:核心认知备忘

**A. "侧面 ≠ 正面"**
侧脸已对,正面差打薄。说明方向对,缺一刀。

**B. "打理不是玄学"**
核心是**吹够时间 + 方向正确**,不是技巧多炫。

**C. "硬件够,卡在状态"**
骨相能撑日系长发,卡你的是皮肤/胡子/姿态。这些都可以改。

**D. "沉没成本不算"**
留了几个月不是必须继续留的理由。决策基于现在和未来,不是过去投入。

**E. "烫发是 5 年踩坑结论"**
不是直觉,是数据。除非未来重新评估,否则不烫。

**F. "自己驾驭不了 ≠ 这个人驾驭不了"**
当前状态驾驭不了,不等于本质驾驭不了。状态可改变。

**G. "AI 图是方向,不是标准"**
AI 永远比真实头发好看(它会偷偷打薄 + 美化皮肤)。
真实头发是事实,AI 是想象。用 AI 找方向,用真人镜子定结果。

**H. "理发师水平不能只看一两张图"**
朋友圈作品要看 10 张以上才能判断他的主营方向和真实水平。
长发作品只有 1-2 张的理发师 → 长发能力未验证 → 只能"试一次"不能"押重注"。

**I. "自己看不到的地方,别人也基本看不到"**
后脑勺别折腾。正面 + 微侧 45 度是别人 90% 的视角。
精力分配应该和"被看到的概率"成正比。

**J. "失败实验是数据,不是失败"**
两次打理失败 → 5 条具体原因 → 下次的 checklist。
没有这两次失败,就没有具体到分钟级的流程。

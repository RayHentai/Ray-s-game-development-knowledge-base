## 项目背景

通过程序生成网格（Mesh）来创建圆柱体形状的地形（类似隧道），原理是：

1. 先生成一个三角形
2. 扩展成矩形

## 已掌握的概念

**顶点 vertices（Vector3）** 网格中每个点在3D世界空间中的坐标，是构成网格的最小单位。

**UV（Vector2）** 每个顶点对应贴图上的采样位置。贴图被归一化为 0~1 的正方形，U是横向，V是纵向。UV与顶点一一对应（`vertices[i]` 对应 `uvs[i]`），与顶点世界坐标完全独立，顶点移动不影响UV。UV超出0~1范围时，贴图根据 Wrap Mode（Repeat/Clamp）处理。

**三角形 triangles（int[]）** 存储顶点的索引，每3个索引描述一个三角形，顶点可被多个三角形复用。从观察者角度看，**顺时针绕序 = 正面可见，逆时针 = 背面不可见**。决定法线方向的是三个顶点在空间中呈现的绕向，与哪个点作为起点无关，同一个三角形的三个索引从任意点开始只要绕向一致结果相同。

**正确的矩形三角形索引示例（4顶点）：**

```
V0---V1    索引：0,1,2  →  V0→V1→V2（顺时针）
|  \ |           1,3,2  →  V1→V3→V2（顺时针）
V2---V3
```

**延伸到6顶点4三角形：**

```
V0---V1    0,1,2  →  ①
|  \ |     1,3,2  →  ②
V2---V3    2,3,4  →  ③
|  \ |     3,5,4  →  ④
V4---V5
```
